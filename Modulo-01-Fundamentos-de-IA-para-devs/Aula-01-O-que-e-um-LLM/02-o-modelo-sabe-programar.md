# O modelo sabe programar?

Você pede: *"crie uma função que valida CPF"*.

Em 3 segundos aparece um código limpo, comentado, com nomes bons.

- Ele **entendeu** o que é um CPF?
- Ele **testou** o código?
- Ele **sabe** se está certo?
