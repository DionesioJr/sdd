# Por que parece que ele entende

- Viu milhões de funções de validação, APIs REST, componentes React.
- Aprendeu os **padrões** que se repetem nesse material.
- Para problemas comuns, o padrão mais provável costuma ser o certo.

Ele **não**:

- consulta um banco de respostas;
- executa o código para ver se funciona (a menos que uma ferramenta faça isso por ele);
- conhece as regras do **seu** negócio.
