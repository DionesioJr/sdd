# Plausível não é correto

O LLM produz o código **mais plausível** para o texto que recebeu.

| Situação | Resultado provável |
|---|---|
| Problema comum, pedido claro | Plausível **e** correto |
| Regra de negócio não informada | Plausível, mas com a regra **inventada** |
| Pedido ambíguo | Plausível para **uma** das interpretações |
| Biblioteca rara ou nova | Plausível, com API **que pode não existir** |

> Quem define o que é correto é você. A IA só consegue acertar o que foi dito.
