# Resumo

- Um LLM gera texto **um token por vez**, escolhendo o pedaço mais plausível.
- Ele aprendeu **padrões**, não as regras do seu sistema.
- Ele produz código **plausível**; correto é o que **você** definiu.
- O mesmo pedido pode gerar respostas diferentes.

**Ligação com o curso**: uma especificação é a forma de dizer à IA o que é correto, antes de ela escrever o código.

**Próxima aula**: o que exatamente o modelo enxerga quando responde.
