# Janela de contexto

O contexto tem um **limite de tokens**: a janela de contexto.

Dentro dela cabe tudo ao mesmo tempo:

| Entra no contexto | Quem coloca |
|---|---|
| Instruções do sistema | A ferramenta |
| Arquivos de instrução do projeto | Você (ex.: `AGENTS.md`) |
| Mensagens e respostas | Você e o modelo |
| Arquivos lidos | O agente |
| Saída de comandos e testes | O agente |
| A resposta que está sendo gerada | O modelo |

O tamanho varia por modelo, de dezenas de milhares a milhões de tokens.
