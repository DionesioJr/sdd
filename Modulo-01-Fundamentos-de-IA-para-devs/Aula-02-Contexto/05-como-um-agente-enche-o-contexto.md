# Como um agente enche o contexto

Pedido: *"corrija o teste que está falhando"*.

| Passo do agente | O que entra no contexto |
|---|---|
| Lista os arquivos do projeto | Árvore de pastas |
| Roda os testes | Saída completa dos testes |
| Lê 4 arquivos | 4 arquivos inteiros |
| Tenta uma correção | O código alterado |
| Roda os testes de novo | Outra saída completa |
| Tenta outra correção | Mais código |

Em poucos minutos, a sua instrução inicial está soterrada.
