# Exercício 2: Mínimo, certo e excessivo

**Objetivo**: comparar a mesma tarefa com três contextos.

Tarefa: *"Crie a função que marca uma tarefa como concluída."*

| Rodada | O que enviar junto |
|---|---|
| Mínimo | Só o pedido |
| Certo | O pedido + o tipo `Tarefa` + a regra: *"só pode concluir se todas as subtarefas estiverem concluídas; registrar a data de conclusão"* |
| Excessivo | O mesmo do "certo" + 3 arquivos de código sem relação com tarefas + um texto longo sobre outra funcionalidade |

Use uma conversa nova para cada rodada. Compare: qual respeitou a regra? Qual inventou coisas?
