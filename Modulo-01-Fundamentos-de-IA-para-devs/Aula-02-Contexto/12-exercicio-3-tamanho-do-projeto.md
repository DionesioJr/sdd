# Exercício 3: Quanto cabe?

**Objetivo**: ter noção do tamanho de um projeto em tokens.

1. Escolha um projeto seu (ou um repositório open source pequeno).
2. Conte os caracteres dos arquivos de código, sem `node_modules`.
3. Estime os tokens: em média, **1 token ≈ 3 a 4 caracteres** de código.
4. Compare com a janela de contexto de um modelo no site do OpenRouter.

**Discussão**: o projeto inteiro cabe? Mesmo que caiba, deveria ir inteiro?
