# Exercício 1: Esse pacote existe?

**Objetivo**: criar o reflexo de conferir dependências.

1. Peça a um modelo pequeno e barato:
   > Liste 5 pacotes npm para validar e formatar números de telefone brasileiros, com o nome exato de cada um.
---

## Exercício 1: Confira cada pacote

2. Para cada pacote, confira no npmjs.com:
   - existe?
   - quem publica?
   - última versão e downloads semanais?
3. Repita com um modelo grande e compare.

**Discussão**: quantos você teria instalado sem conferir?
