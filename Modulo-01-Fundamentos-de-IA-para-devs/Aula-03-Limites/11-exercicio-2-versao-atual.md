# Exercício 2: Que versão você conhece?

**Objetivo**: perceber a data de corte na prática.

1. Escolha um framework que você usa (React, Next.js, Express, Prisma...).
2. Pergunte ao modelo:
   > Qual é a versão mais recente do [framework] e quais foram as principais mudanças dela?
3. Compare com o site oficial ou o changelog.
4. Peça um exemplo de código e verifique se usa a API atual.

**Discussão**: o que você precisaria colocar no contexto para o modelo acertar?
