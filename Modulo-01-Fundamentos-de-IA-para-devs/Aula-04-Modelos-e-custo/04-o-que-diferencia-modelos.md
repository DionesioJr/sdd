# O que diferencia um modelo de outro

| Característica | Pergunta prática |
|---|---|
| Capacidade | Resolve problemas difíceis, de várias etapas? |
| Uso de ferramentas | Funciona bem como agente (ler arquivos, rodar comandos)? |
| Janela de contexto | Quanto cabe numa sessão? |
| Velocidade | Quanto tempo você espera por resposta? |
| Preço | Quanto custa por milhão de tokens? |

Não existe o melhor modelo. Existe o melhor modelo **para a tarefa**.
