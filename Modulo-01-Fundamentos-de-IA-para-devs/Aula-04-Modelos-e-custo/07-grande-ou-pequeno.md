# Modelo grande ou pequeno?

| Use modelo grande para | Use modelo pequeno para |
|---|---|
| Refinar ideias e escrever specs | Tarefas pequenas e bem especificadas |
| Decidir arquitetura | Código repetitivo seguindo um padrão |
| Depurar problemas difíceis | Testes a partir de critérios claros |
| Revisar código crítico | Renomear, formatar, documentar |

> Quanto melhor a especificação, menor o modelo que dá conta da tarefa.
