# Módulo 01: Fundamentos de IA para devs

Objetivo: entender o suficiente sobre LLMs para prever quando a IA vai acertar, quando vai errar e por que o curso usa especificações.

## Por que este módulo existe

É o ponto de partida do curso: antes de qualquer método, é preciso saber **por que a IA erra com tanta confiança**. Tudo que vem depois (spec, design, testes, automação) é a resposta a esses limites.

**Sem este módulo**: você trata a IA como se ela entendesse o seu sistema, aceita o que parece certo e descobre os erros em produção.

**Ganho real**: você prevê onde a IA acerta e onde erra, e já sabe, antes do Módulo 02, que o caminho é **definir o correto antes e verificar depois**.

## Preparação

- Conta no [OpenRouter](https://openrouter.ai) com alguns dólares de crédito.
- Navegador. Neste módulo os exercícios usam o chat do OpenRouter; a instalação do agente Pi fica para o Módulo 02.

## Como as aulas são organizadas

1. **Problema**: uma situação real que o aluno já viveu ou vai viver.
2. **Conceito**: só o que muda a forma de trabalhar.
3. **Consequência para código**: o que isso significa na prática.
4. **Exercícios**: o aluno observa o fenômeno com as próprias mãos.
5. **Ligação com SDD**: por que o método do curso resolve o problema.
