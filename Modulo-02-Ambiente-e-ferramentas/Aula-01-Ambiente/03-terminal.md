# O terminal é a interface do agente

O Pi não tem janelas: ele vive no terminal. Tudo que ele faz, você também faz, e é por isso que você consegue **conferir**.

| Comando | O que faz |
|---|---|
| `pwd` / `cd pasta` | onde estou / entrar numa pasta |
| `ls` | listar arquivos |
| `mkdir nome` | criar pasta |
| `node -v` | versão do Node |
| `npm run teste` | rodar um script do projeto |

Se o agente roda um comando, **você deve entender o que ele faz**.
