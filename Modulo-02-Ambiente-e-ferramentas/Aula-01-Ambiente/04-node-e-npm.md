# Node.js e npm

- **Node.js** executa JavaScript e TypeScript fora do navegador.
- **npm** instala bibliotecas e roda scripts.
- **`package.json`** descreve o projeto: nome, scripts e dependências.

```bash
node -v        # use uma versão LTS
npm -v
npm init -y    # cria o package.json
```

**Regra do curso**: o projeto declara a versão do Node que usa. Assim, você e o agente sabem qual é a certa.
