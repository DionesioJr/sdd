# VS Code: onde você lê o que o agente fez

O agente escreve. **Você revisa.** O VS Code serve para:

1. ver o **diff** do que mudou;
2. navegar pelo código e ler o que foi gerado;
3. usar o terminal integrado;
4. ver os erros de tipo sublinhados na hora.

Aprender a ler diffs é uma das habilidades mais valiosas do curso.
