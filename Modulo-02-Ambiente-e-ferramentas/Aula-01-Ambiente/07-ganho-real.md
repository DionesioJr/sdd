# O ganho real

| Sem isso | Com isso |
|---|---|
| Cada máquina com uma versão de Node | Versão declarada no projeto, igual para todos |
| O agente gasta contexto consertando o ambiente | O agente começa direto no trabalho |
| Erro de API inventada só aparece em execução | O compilador avisa antes de rodar |
| Código gerado aceito sem olhar | Diff lido no editor antes de aceitar |

**Ganho real**: o tempo que seria gasto "consertando o ambiente" volta para o trabalho, e o compilador pega uma parte dos erros da IA antes de você.
