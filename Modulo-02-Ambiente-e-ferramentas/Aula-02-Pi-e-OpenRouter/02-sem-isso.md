# Preso a um provedor, sem controle do gasto

Duas situações reais:

- Você assina uma ferramenta amarrada a **um** modelo. Quando surge um melhor (ou mais barato), você não pode usá-lo.
- Você cola a chave de API num arquivo do projeto, faz commit e o repositório vai para o GitHub. Alguém usa a chave e a fatura chega.

Qual das duas custa mais caro?
