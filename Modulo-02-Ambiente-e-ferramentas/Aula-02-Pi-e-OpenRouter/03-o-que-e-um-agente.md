# O que é um agente de código

Um modelo sozinho só gera texto. Um **agente** coloca ferramentas ao redor dele:

Ciclo do agente: Pedido → Modelo decide → Usa uma ferramenta → Lê o resultado → Repete até terminar

O Pi trabalha com poucas ferramentas simples: **ler** arquivos, **escrever**, **editar** e **rodar comandos**.

Tudo que ele lê e todo resultado de comando **entram no contexto** (Módulo 01, Aula 02).
