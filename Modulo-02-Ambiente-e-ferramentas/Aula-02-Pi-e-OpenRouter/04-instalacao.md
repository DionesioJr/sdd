# Instalando o Pi

Siga a instalação oficial em **pi.dev**. O instalador e o nome do pacote npm podem mudar, e a página oficial é sempre a referência.

```bash
pi --version   # confirma que instalou
```

Depois, dentro da pasta do projeto, basta chamar:

```bash
cd gestor-de-tarefas
pi
```

**Regra**: o Pi sempre é aberto **dentro da pasta do projeto**. É lá que ele enxerga e altera arquivos.
