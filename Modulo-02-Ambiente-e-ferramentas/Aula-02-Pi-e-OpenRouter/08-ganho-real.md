# O ganho real

| Sem isso | Com isso |
|---|---|
| Amarrado a um único modelo | Troca de modelo com um comando |
| Chave no código, risco de vazamento | Chave fora do projeto, com limite de crédito |
| Gasto invisível | Consumo visível no painel do OpenRouter |
| Método preso à ferramenta | Método vale para qualquer agente |

**Ganho real**: liberdade para usar o melhor modelo para cada tarefa e um teto de gasto que você mesmo define.
