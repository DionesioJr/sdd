# Exercício 1: Instalar e configurar

**Objetivo**: ter o Pi rodando com um modelo do OpenRouter.

1. Instale o Pi pelas instruções de **pi.dev**.
2. Crie uma chave no OpenRouter e defina um **limite de crédito** baixo.
3. Configure a chave fora do projeto.
4. Abra `pi` dentro de `gestor-de-tarefas` e use `/model` para escolher um modelo.

**Observe**: o Pi respondeu? Qual modelo você escolheu e por quê?
