# O repositório e as três áreas

```bash
git init          # transforma a pasta num repositório
git status        # o que mudou desde o último registro
```

Fluxo: Diretório de trabalho → Área de preparação (`git add`) → Histórico (`git commit`)

- **Diretório de trabalho**: seus arquivos agora.
- **Preparação**: o que vai entrar no próximo registro.
- **Histórico**: os registros (commits) que não se perdem.
