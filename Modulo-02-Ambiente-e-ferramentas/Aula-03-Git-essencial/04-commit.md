# Commit: um ponto de restauração

```bash
git add .
git commit -m "feat: tipo Tarefa e função concluir"
```

**Hábito do curso**: **antes** de pedir algo ao agente, a árvore está limpa (`git status` sem alterações). Assim, tudo que aparecer em `git diff` foi feito por ele.

Boas mensagens dizem **o quê** e **por quê**, em uma linha.
