# O ganho real

| Sem isso | Com isso |
|---|---|
| Pedido ruim: horas tentando desfazer na mão | `git restore .` e você está de volta |
| "O que o agente mudou?" Ninguém sabe | `git diff` mostra tudo |
| Experimento contamina a versão estável | Branch descartável |
| Medo de deixar o agente mexer | Liberdade para tentar, porque voltar é barato |

**Ganho real**: o agente passa de risco a ferramenta, porque errar sai barato.
