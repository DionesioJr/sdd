# Exercício 2: Mapear para o ciclo

**Objetivo**: fixar o ciclo do SDD como linguagem comum.

1. Desenhe numa folha o ciclo: **Especificar → Projetar → Tarefas → Implementar → Verificar → Entregar**.
2. Posicione, em cada etapa, o documento correspondente de cada ferramenta que você leu.
3. Marque onde **você** acha que um humano precisa aprovar.

**Discussão**: se você tivesse de explicar SDD a um colega em um minuto, usando só esse desenho, o que diria?
