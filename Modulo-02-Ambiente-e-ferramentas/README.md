# Módulo 02: Ambiente e ferramentas

Objetivo: montar o lugar de trabalho (terminal, Node, TypeScript, VS Code), instalar o agente Pi com OpenRouter, ter uma rede de segurança com Git e conhecer o ecossistema de SDD.

## Por que este módulo existe

O Módulo 01 explicou **por que a IA erra**. Agora falta um lugar seguro para trabalhar com ela. O agente lê arquivos, edita código e roda comandos na sua máquina: sem ambiente confiável e sem como desfazer, cada erro dele vira um problema seu.

**Sem este módulo**: ambientes diferentes em cada máquina, chaves de API em arquivos do repositório e nenhuma forma de voltar atrás quando o agente reescreve metade do projeto.

**Ganho real**: agente funcionando em minutos, projeto versionado e qualquer estrago reversível com um comando.

## Preparação

- Computador com permissão para instalar programas.
- Conta no [OpenRouter](https://openrouter.ai) com crédito (a mesma do Módulo 01).
- Conta no GitHub (útil, mas não obrigatória neste módulo).

## Entregável do módulo

A pasta `gestor-de-tarefas/`, versionada com Git, com TypeScript configurado e o Pi respondendo dentro dela. É o início do projeto que atravessa o curso.
