# O ganho real

| Sem isso | Com isso |
|---|---|
| O agente decide por você | Você decide, o agente executa |
| Várias rodadas de "não era isso" | Menos rodadas e menos tokens |
| Código que parece bom, mas segue outro caminho | Código dentro das restrições |
| "Pronto" é opinião | "Pronto" tem um critério visível |

**Ganho real**: cada frase no pedido substitui uma rodada de correção. Menos tempo, menos tokens e menos código descartado.
