# Exercício 1: Reescrever pedidos fracos

**Objetivo**: transformar pedidos vagos em pedidos completos.

Reescreva cada pedido com **objetivo, contexto, restrições e formato**:

1. *"Faça uma função para listar tarefas."*
2. *"Arrume os bugs do projeto."*
3. *"Deixe o código mais bonito."*

**Observe**: qual informação você teve de **inventar** ou buscar no projeto para completar cada pedido?
