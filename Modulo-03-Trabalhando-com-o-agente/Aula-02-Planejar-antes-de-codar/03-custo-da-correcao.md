# O custo da correção cresce

Corrigir no: Plano → Código → Testes → Produção

Cada etapa à frente custa mais para voltar atrás.

- No **plano**, você muda uma linha de texto.
- No **código**, você descarta ou reescreve arquivos.
- Em **produção**, você corrige com usuários afetados.

Este é o princípio que sustenta o SDD: **decidir cedo, em texto**.
