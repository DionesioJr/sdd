# Como pedir um plano

O Pi não tem um modo de plano embutido: **você pede**.

```
Quero adicionar o filtro de tarefas atrasadas.
NÃO escreva código ainda. Antes, me entregue:
1. os arquivos que pretende alterar ou criar;
2. os passos, em ordem;
3. riscos e dúvidas que você tem;
4. perguntas que eu deveria responder.
Espere minha aprovação.
```

A frase **"espere minha aprovação"** é a parte mais importante.
