# Discordar do plano

O plano é uma **proposta**. Leia e:

- **Corte** o que não pediu: "não crie a pasta `utils`".
- **Pergunte** alternativas: "há uma forma mais simples?"
- **Corrija** premissas: "o prazo é opcional".
- **Responda** às perguntas que ele fez.

Só aprove quando o plano refletir **o que você decidiu**.
