# O roteiro de leitura

Antes de aceitar, responda:

1. **Faz o que pedi?** Nem mais, nem menos.
2. **Mudou algo que eu não pedi?** Veja os arquivos alterados.
3. **Trouxe dependências novas?** Elas existem e são confiáveis?
4. **Trata erros?** O que acontece quando algo falha?
5. **Expõe algo?** Segredos, dados pessoais, entradas não validadas.

Use `git diff`. Leia o **diff**, não o arquivo inteiro.
