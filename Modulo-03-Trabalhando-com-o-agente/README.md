# Módulo 03: Trabalhando com o agente

Objetivo: dominar a conversa com o agente: pedir bem, planejar antes de codar, ler o que ele gera e saber iterar ou recomeçar.

## Por que este módulo existe

O ambiente está pronto e o agente responde. Mas **a qualidade do resultado depende de como você conversa**. Nenhum método de especificação funciona se o pedido for vago, se o código for aceito sem leitura ou se a conversa só piorar a cada tentativa.

**Sem este módulo**: pedidos soltos, respostas que variam, código aceito sem entender e conversas longas que só acumulam erro.

**Ganho real**: pedidos que acertam de primeira com mais frequência, plano aprovado antes de qualquer linha de código e o hábito de revisar que será a base de todo o resto.

## Preparação

- A pasta `gestor-de-tarefas/` do Módulo 02, com Git e Pi funcionando.
- Árvore de trabalho limpa (`git status` sem alterações) no início de cada exercício.

## Entregável do módulo

Um pequeno gestor de tarefas em linha de comando (em memória), feito por você e pelo agente com pedidos bem formulados, plano aprovado e código revisado. Ele servirá de comparação no Módulo 04.
