# O ganho real

| Sem isso | Com isso |
|---|---|
| O sistema só existe em conversas passadas | O sistema está descrito num arquivo |
| Cada sessão adivinha de novo | Cada sessão lê o mesmo texto |
| Mudar é arriscado | Mudar é editar a spec, depois o código |
| "Está certo?" é opinião | "Está certo?" é comparar com a spec |

**Ganho real**: o conhecimento do projeto deixa de morar na sua cabeça e na conversa e passa a viver num arquivo que qualquer sessão e qualquer pessoa pode ler.
