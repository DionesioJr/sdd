# Exercício 1: Cinco pedidos soltos

**Objetivo**: ver o limite acontecer.

1. Crie uma pasta `vibe/` fora do projeto e inicie um novo repositório.
2. Em **sessões separadas** (feche o Pi entre cada uma), faça estes pedidos curtos ao agente, um por vez:
   1. *"Crie um gestor de tarefas web simples com TypeScript."*
   2. *"Adicione prioridade às tarefas."*
   3. *"Permita filtrar por data."*
   4. *"Tarefas concluídas devem aparecer separadas."*
   5. *"Adicione responsável por tarefa."*
3. Faça um commit a cada pedido.

---

## Exercício 1: Observe

4. Liste: o que quebrou? O que ficou duplicado? O que o agente decidiu sem você?
