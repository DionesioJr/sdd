# Exercício 2: Meia página de spec

**Objetivo**: sentir o efeito de decidir antes, de forma bem simples.

1. Em outra pasta `com-spec/`, escreva um `spec.md` de **meia página** com:
   - o que o sistema é e para quem;
   - os campos de uma tarefa (nomes finais);
   - cinco comportamentos esperados;
   - o que **não** faz.
2. Peça os **mesmos cinco pedidos**, agora começando cada sessão com: *"Leia `spec.md`."*

**Observe**: compare as duas pastas. Qual teve menos contradições e retrabalho? Quanto custou escrever a meia página?
