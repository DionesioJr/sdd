# Resumo

- Vibe coding serve para protótipo descartável, não para o que será mantido.
- Sintomas: decisões implícitas, amnésia, contradições, "pronto" subjetivo, mudança em cascata.
- A raiz: o "correto" não está escrito.
- A solução: escrever uma vez, reutilizar sempre.

**O ganho real**: o conhecimento do projeto passa a viver num arquivo.

**Próxima aula**: escrever a spec não é o fim. Existe uma **sequência de fases**, e a ordem importa. Vamos conhecer o ciclo do SDD.
