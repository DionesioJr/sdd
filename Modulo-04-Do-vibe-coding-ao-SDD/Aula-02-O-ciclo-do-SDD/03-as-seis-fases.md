# As seis fases

Ciclo: Especificar → Projetar → Quebrar em tarefas → Implementar → Verificar → Entregar

| Fase | Pergunta |
|---|---|
| Especificar | **O quê** e **para quem**? |
| Projetar | **Como** será construído? |
| Tarefas | **O que fazer agora**? |
| Implementar | Como executar **esta** tarefa? |
| Verificar | Cumpre o que foi especificado? |
| Entregar | Está no ar e funcionando? |
