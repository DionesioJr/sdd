# Portões de aprovação

Entre as fases, **uma pessoa aprova**:

Especificar → Aprovar → Projetar → Aprovar → Tarefas → Aprovar → Implementar

- O agente **propõe**; a pessoa **decide**.
- Aprovar é ler, questionar e dizer "pode seguir".
- Sem aprovação, o agente não avança.

Esse é o controle humano que torna a automação segura (Níveis 4 e 5).
