# O ciclo realimenta

Depois de entregar, o **feedback** (usuários, logs, bugs, novas ideias) volta à primeira fase:

Entrega → Feedback → Nova spec → Novo ciclo

- O SDD **não é cascata**: os ciclos são **curtos** (uma funcionalidade por vez).
- Descobertas na implementação voltam para a spec.

Uma única funcionalidade percorre o ciclo inteiro em horas ou dias, não em meses.
