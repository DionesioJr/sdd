# Exercício 1: Mapear um pedido no ciclo

**Objetivo**: ver uma funcionalidade percorrendo as fases.

Pegue a funcionalidade *"o usuário marca uma tarefa como concluída e vê quando concluiu"*.

Para cada fase, escreva **uma linha** sobre o que seria produzido:

1. Especificar: …
2. Projetar: …
3. Tarefas: …
4. Implementar: …
5. Verificar: …
6. Entregar: …

**Observe**: que fase foi mais difícil de descrever? Por quê?

<!--
Tempo: 20 min.
Normalmente, projetar e verificar são as mais difíceis para quem vem do vibe coding.
