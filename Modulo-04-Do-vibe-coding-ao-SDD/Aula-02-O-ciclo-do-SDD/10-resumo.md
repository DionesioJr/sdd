# Resumo

- O ciclo: especificar, projetar, tarefas, implementar, verificar, entregar.
- Cada fase responde a uma pergunta diferente.
- A ordem importa: cada fase alimenta a seguinte.
- Uma pessoa aprova entre as fases.
- O ciclo é curto e realimentado pelo feedback.

**O ganho real**: você sabe em que fase está e o que falta para avançar.

**Próxima aula**: cada fase produz um **documento**. Vamos conhecer a anatomia deles e como se ligam.
