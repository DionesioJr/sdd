# Os seis documentos

### 1. Product Spec

**O quê e para quem.** Problema, requisitos, critérios de aceite.

### 2. Design / Tech Spec

**Como será construído.** Stack, componentes, dados, API.

### 3. ADR

**Por que decidimos assim.** Uma decisão por arquivo.

### 4. Tarefas

**O que fazer agora.** Lista ordenada, ligada aos requisitos.

### 5. Taskfile

**Como executar esta tarefa.** Descrição e contexto de uma só tarefa.

### 6. AGENTS.md e guidelines

**O que o agente precisa saber.** Regras fixas do projeto.
