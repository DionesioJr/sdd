# Como se ligam

Cadeia: Requisito → Decisão de design → Tarefa → Código → Teste

Cada elo aponta para o anterior:

- A **tarefa** diz qual requisito atende.
- O **teste** verifica um critério de aceite.
- A **decisão** (ADR) explica uma escolha do design.

Essa cadeia é a **rastreabilidade**. Ela responde: *"por que este código existe?"*
