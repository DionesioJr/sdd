# O ganho real

| Sem isso | Com isso |
|---|---|
| Documento único, enorme, contraditório | Cada documento responde uma pergunta |
| O agente recebe tudo | O agente recebe só o que a tarefa pede |
| Ninguém sabe onde mudar | Cada mudança tem um lugar |
| "Por que isso existe?" fica sem resposta | A cadeia de rastreabilidade responde |

**Ganho real**: contexto certo para o agente, mudanças com endereço e revisão possível.
