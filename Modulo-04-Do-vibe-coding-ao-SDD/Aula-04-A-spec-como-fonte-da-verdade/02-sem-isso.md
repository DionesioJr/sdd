# A spec que mente

Três meses depois, a spec diz uma coisa e o sistema faz outra:

- Alguém mudou o código direto, "só um ajuste".
- A spec nunca foi atualizada.
- Um agente novo lê a spec, implementa conforme ela e **desfaz** o ajuste.

Agora ninguém confia na spec, e ela vira **lixo**.

- Qual é o primeiro sinal de que isso está acontecendo?
