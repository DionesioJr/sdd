# A regra do curso

**A spec é a fonte da verdade.** O código segue a spec, e a spec muda **antes** do código.

Fluxo de uma mudança: Muda a spec → Pessoa aprova → Atualiza tarefas → Muda o código → Verifica

- Quer alterar um comportamento? **Edite o requisito primeiro.**
- O agente recebe a spec atualizada como contexto.
- O teste é escrito a partir do critério de aceite.
