# Quando o código descobre algo

Às vezes, a implementação revela que a spec estava errada ou incompleta:

1. **Pare.**
2. Registre a descoberta na spec (ou num ADR).
3. Aprove a mudança.
4. **Só então** continue o código.

A realidade vence, mas **deve ser registrada**. Nunca deixe a descoberta só no código.
