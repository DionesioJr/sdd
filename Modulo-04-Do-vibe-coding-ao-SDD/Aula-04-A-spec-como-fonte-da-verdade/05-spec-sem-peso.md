# Spec não é cascata

- **Não** é escrever tudo antes de codar: é o **suficiente** para a próxima funcionalidade.
- **Não** é um documento congelado: muda sempre que o entendimento muda.
- **Não** é burocracia: é a memória do projeto, e custa menos que a conversa repetida.

Uma boa spec é a **menor** que elimina as decisões erradas.
