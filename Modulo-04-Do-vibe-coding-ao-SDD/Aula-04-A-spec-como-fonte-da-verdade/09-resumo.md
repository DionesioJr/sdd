# Resumo

- A spec é a fonte da verdade: o código a segue.
- A spec muda **antes** do código.
- Descobertas da implementação voltam para a spec, com registro.
- Spec desatualizada é pior que nenhuma.
- Spec boa é a menor que evita decisões erradas.

**O ganho real**: uma referência confiável para pessoas e agentes.
