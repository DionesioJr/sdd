# Módulo 04: Do vibe coding ao SDD

Objetivo: entender, com a própria experiência, por que o pedido solto não escala, conhecer o ciclo do SDD, o papel de cada documento e a regra central: a spec é a fonte da verdade.

## Por que este módulo existe

No Módulo 03 você aprendeu a pedir bem, planejar e revisar. Isso resolve **uma tarefa**. Quando o projeto tem dezenas de tarefas, sessões diferentes e mais de uma pessoa, a conversa deixa de ser suficiente: ninguém lembra o que foi decidido, o agente contradiz o que fez ontem e cada mudança quebra outra coisa.

**Sem este módulo**: o aluno entra no Nível 2 achando que spec é "burocracia" e abandona o método na primeira pressa.

**Ganho real**: você vê o problema acontecer antes de ver a solução, entende por que cada documento existe e passa a tratar a spec como o lugar onde se decide.
