# Requisitos funcionais

O que o sistema **faz**. Uma frase, um comportamento.

```
RF-01  O usuário pode criar uma tarefa com título (obrigatório),
       descrição, prazo e prioridade.
RF-02  O usuário pode listar suas tarefas e filtrá-las por status.
RF-03  O usuário pode marcar uma tarefa como concluída.
```

Boas práticas:

- **Um comportamento** por requisito;
- verbo no presente, voz ativa;
- diz **o quê**, nunca **como** (nada de tecnologia).
