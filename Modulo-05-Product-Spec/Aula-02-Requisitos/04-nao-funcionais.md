# Requisitos não funcionais

**Como** o sistema se comporta: qualidade, e não função.

| Categoria | Exemplo **verificável** |
|---|---|
| Desempenho | Listar 500 tarefas leva menos de 1 segundo |
| Segurança | Senhas nunca são guardadas em texto puro |
| Acessibilidade | Todas as ações funcionam só com teclado |
| Usabilidade | Criar a primeira tarefa em até 3 cliques |

Se não dá para **medir**, ainda não é um requisito.
