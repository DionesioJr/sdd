# Numerar para rastrear

Cada requisito tem um **ID estável**: `RF-01`, `RNF-02`.

- A **tarefa** cita o ID que atende.
- O **teste** cita o ID que verifica.
- O **PR** cita o ID que entrega.

Não renumere ao remover: marque como **removido**. Assim, referências antigas continuam fazendo sentido.
