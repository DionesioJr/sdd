# O ganho real

| Sem isso | Com isso |
|---|---|
| "Rápido e fácil", cada um entende de um jeito | Requisito medido, todos entendem igual |
| O agente adiciona extras | O agente respeita o que ficou de fora |
| Não se sabe o que cada código atende | Cada trecho aponta para um ID |
| Qualidade fica para o fim | Qualidade entra desde o início |

**Ganho real**: o agente implementa o que foi pedido, sem ampliar nem reduzir o escopo por conta própria.
