# Exercício 1: Do desejo ao requisito

**Objetivo**: reescrever desejos vagos.

Transforme em requisitos funcionais ou não funcionais verificáveis:

1. *"O sistema precisa ser bem organizado."*
2. *"As tarefas têm que aparecer rápido."*
3. *"O usuário precisa ter controle das suas tarefas."*
4. *"Tem que ser seguro."*

**Observe**: que informações você precisou **decidir** para cada um (quantos segundos, quais dados, o que é "controle")?
