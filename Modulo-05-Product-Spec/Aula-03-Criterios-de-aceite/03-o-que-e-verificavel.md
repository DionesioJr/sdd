# O que é verificável

Um critério é verificável quando **duas pessoas diferentes chegam ao mesmo veredito**.

| Vago | Verificável |
|---|---|
| "Valida o título" | "Título vazio ou só com espaços é recusado com a mensagem *Título é obrigatório*" |
| "Lista rápida" | "Listar 500 tarefas leva menos de 1 s" |
| "Mostra erro" | "Em falha de rede, exibe *Tente novamente* e mantém os dados digitados" |

Teste mental: **dá para escrever um teste automatizado disso?**
