# Dado, Quando, Então

Para **fluxos** do usuário:

```
Dado   que existe uma tarefa pendente
Quando o usuário clica em "Concluir"
Então  a tarefa aparece como concluída
E      a data de conclusão é registrada
```

- **Dado**: o estado inicial.
- **Quando**: a ação.
- **Então**: o resultado observável.

Cada critério vira um **teste** quase literal (Módulo 08).
