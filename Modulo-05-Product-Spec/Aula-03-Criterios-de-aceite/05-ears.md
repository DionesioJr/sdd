# EARS: requisitos em frases padrão

Para **regras do sistema**. Cinco padrões:

| Tipo | Modelo |
|---|---|
| Sempre | O sistema deve … |
| Evento | **Quando** … , o sistema deve … |
| Estado | **Enquanto** … , o sistema deve … |
| Indesejado | **Se** … , **então** o sistema deve … |
| Opcional | **Onde** … , o sistema deve … |

*Ex.: Se o título estiver vazio, então o sistema deve recusar a tarefa e exibir "Título é obrigatório".*
