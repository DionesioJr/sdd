# O ganho real

| Sem isso | Com isso |
|---|---|
| "Pronto" é opinião do agente | "Pronto" é um conjunto de critérios |
| Só o caminho feliz | Erros e bordas especificados |
| Testes escritos a partir do código | Testes escritos a partir da spec |
| Discussões sobre o que era para fazer | Consulta ao critério |

**Ganho real**: cada critério vira um teste, então a spec passa a **verificar** o código, e não só a descrevê-lo.
