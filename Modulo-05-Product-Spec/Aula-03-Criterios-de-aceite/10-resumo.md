# Resumo

- Critério verificável: pessoas diferentes chegam ao mesmo veredito.
- **Dado/Quando/Então** para fluxos; **EARS** para regras.
- Sempre cubra vazio, grande, inválido, falha e repetição.
- Cada critério será um teste.

**O ganho real**: a spec passa a verificar o código.

**Próxima aula**: agora você tem critérios para tudo. Quanto disso cabe na primeira versão? Vamos definir o **escopo** e o MVP.
