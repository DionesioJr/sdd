# MVP: a menor versão que entrega valor

**MVP** (produto mínimo viável) responde: *"qual é o mínimo para o usuário resolver o problema principal?"*

Fluxo: Problema → Essencial → MVP → Feedback → Próxima versão

- **Essencial**: sem isso o problema continua.
- **Futuro**: bom, mas pode esperar.

Para o gestor, o essencial é: criar, listar, filtrar e concluir tarefas. Equipes e notificações ficam para o futuro.
