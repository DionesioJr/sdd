# Como separar o essencial

Para cada requisito, pergunte:

1. **Sem ele, o usuário resolve o problema?** Se não, é essencial.
2. **Dá para entregar depois sem refazer o que já existe?** Se sim, é futuro.
3. **Valida uma hipótese arriscada?** Se sim, faça cedo.

Classifique em: **Deve ter · Deveria ter · Poderia ter · Não agora**.

As ideias do futuro vão para uma lista (`## Futuro`) no documento. **Nada se perde, nada se constrói.**
