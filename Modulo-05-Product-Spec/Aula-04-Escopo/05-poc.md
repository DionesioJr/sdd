# Quando fazer uma PoC

**PoC** (prova de conceito) responde **uma pergunta de viabilidade**: *"isso é possível?"*

| PoC | MVP |
|---|---|
| Pergunta: dá para fazer? | Pergunta: o usuário quer? |
| Código **descartável** | Código que evolui |
| Sem spec completa | Spec e critérios |

Regra: **PoC não vai para produção.** Se funcionar, escreva a spec e construa de novo.
