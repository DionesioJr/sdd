# O ganho real

| Sem isso | Com isso |
|---|---|
| Constrói tudo porque é barato | Constrói só o essencial |
| Revisa e mantém código desnecessário | Menos código para ler e testar |
| Ideias perdidas ou implementadas sem critério | Ideias guardadas em "Futuro" |
| PoC vira produto por acidente | PoC descartada, produto especificado |

**Ganho real**: o MVP chega antes, é mais fácil de revisar e valida a ideia com menos investimento.
