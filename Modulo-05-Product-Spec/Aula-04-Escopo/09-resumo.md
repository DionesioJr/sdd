# Resumo

- Construir é barato; revisar e manter é caro.
- MVP: o mínimo que resolve o problema principal.
- Ideias do futuro vão para uma lista, sem implementação.
- PoC responde uma pergunta de viabilidade e é descartável.

**O ganho real**: MVP mais cedo, com menos código para revisar.

**Próxima aula**: a spec está escrita. **Ela está certa?** Vamos revisá-la com a IA antes de gastar tempo em design.
