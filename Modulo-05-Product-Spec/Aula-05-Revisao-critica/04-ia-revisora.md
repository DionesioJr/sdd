# A IA como revisora

```
Leia docs/requirements.md como se fosse implementá-lo amanhã.
Liste, em tabelas separadas:
1. Ambiguidades (cite o trecho e as interpretações possíveis)
2. Contradições entre requisitos
3. Lacunas (o que você teria de inventar)
4. Itens não verificáveis
Para cada achado, faça uma pergunta que eu possa responder.
NÃO reescreva o documento.
```

Ela **aponta**; você **decide**. Cada achado vira uma pergunta que você responde, e a resposta entra no texto.
