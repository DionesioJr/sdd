# O ganho real

| Sem isso | Com isso |
|---|---|
| Contradições descobertas no código | Descobertas na leitura da spec |
| O agente inventa o que faltou | Lacunas viram decisões escritas |
| Spec "aprovada" por cansaço | Aprovação consciente, depois de uma revisão |
| Um mal-entendido vira semanas de retrabalho | Um mal-entendido vira uma pergunta |

**Ganho real**: a spec chega ao design sem defeitos que se multiplicariam em design, tarefas e código.
