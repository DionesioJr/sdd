# Exercício 1: Cace os defeitos

**Objetivo**: reconhecer os quatro tipos sem ajuda.

Leia o trecho e classifique cada problema:

```
RF-01 O usuário pode criar tarefas.
RF-02 A lista mostra as tarefas mais recentes primeiro.
RF-03 A lista é ordenada por prazo.
RF-04 O usuário pode excluir tarefas.
RF-05 O sistema deve ser fácil de usar.
```

1. Há ambiguidade? Onde?
2. Há contradição?
3. Que lacunas existem (ex.: excluir pede confirmação?)
4. Quais itens não são verificáveis?
