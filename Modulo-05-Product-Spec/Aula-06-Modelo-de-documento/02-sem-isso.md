# Cada spec num formato

Hoje uma spec começa pelo problema. Amanhã, por uma lista de telas. Depois de amanhã, é um parágrafo corrido.

- O agente não sabe **onde** procurar o que precisa.
- O revisor não sabe **o que esperar**.
- Cada projeto reinventa a roda.

Um **modelo** padroniza, e padronizar economiza contexto.
