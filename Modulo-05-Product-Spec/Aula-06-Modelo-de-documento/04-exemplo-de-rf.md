# Um requisito completo

```md
### RF-01 Criar tarefa  (MVP)

O usuário pode criar uma tarefa com título, descrição,
prazo e prioridade.

**Critérios de aceite**
- Dado que o usuário preencheu o título,
  quando salvar, então a tarefa aparece na lista.
- Se o título estiver vazio, então o sistema deve
  recusar e exibir "Título é obrigatório".
- O título aceita até 120 caracteres.
```

Requisito, escopo e critérios **juntos**, no mesmo lugar.
