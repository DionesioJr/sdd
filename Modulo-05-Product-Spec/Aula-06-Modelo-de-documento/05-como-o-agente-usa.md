# Como o agente usa o documento

- Cite o arquivo no pedido: *"Leia `docs/requirements.md`, em especial RF-01."*
- Peça o plano **a partir** dos requisitos.
- Cada tarefa vai citar o ID que atende.

O que **não** vai no documento: tecnologia, telas detalhadas, decisões de código. Isso é o **design**, no próximo módulo.

**Teste de leitura**: peça a uma sessão nova para resumir o que o sistema faz e listar perguntas. Se ela errar, a spec não está clara.
