# O ganho real

| Sem isso | Com isso |
|---|---|
| Formato diferente a cada spec | Estrutura fixa e conhecida |
| O agente procura o que precisa | O agente encontra pelo ID |
| Revisão sem roteiro | Revisão seção a seção |
| "Será que ficou claro?" | Teste de leitura responde |

**Ganho real**: uma Product Spec pronta para alimentar o design e as tarefas, reutilizável em toda sessão.
