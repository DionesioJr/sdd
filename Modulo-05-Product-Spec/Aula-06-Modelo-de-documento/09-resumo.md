# Resumo

- Um modelo fixo torna a spec legível para pessoas e agentes.
- Cada RF reúne requisito, escopo e critérios.
- O documento diz **o quê**; tecnologia é design.
- O teste de leitura mede a clareza.

**O ganho real**: uma Product Spec pronta para o resto do ciclo.

**Próximo módulo**: com o "o quê" definido, falta o "como". O **Design** responde: qual tecnologia, quais componentes, quais contratos.
