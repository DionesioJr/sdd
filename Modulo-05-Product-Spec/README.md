# Módulo 05: Product Spec

Objetivo: transformar uma ideia bruta em um `requirements.md` que define o problema, os requisitos, os critérios de aceite e o escopo do MVP do gestor de tarefas.

## Por que este módulo existe

O Nível 1 mostrou que o "correto" precisa estar escrito. Este é o primeiro documento do ciclo: a **Product Spec**. Tudo que vem depois (design, tarefas, código, testes) é conferido contra ela.

**Sem este módulo**: a IA constrói **o que você pediu**, não **o que você precisava**. O mal-entendido só aparece com o sistema pronto, quando corrigir custa mais.

**Ganho real**: um documento que define "pronto" antes do primeiro código, com critérios que viram testes e um escopo que impede o agente de inventar funcionalidades.

## Preparação

- A pasta `gestor-de-tarefas/` com Git e o Pi funcionando.
- Crie a pasta `docs/` dentro do projeto.

## Entregável do módulo

`docs/requirements.md` do gestor de tarefas, revisado e aprovado por você, com requisitos numerados, critérios de aceite e escopo do MVP.
