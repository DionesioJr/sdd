# Sugestão do curso

Para o gestor de tarefas, a stack de referência é:

| Camada | Escolha | Por quê |
|---|---|---|
| Linguagem | TypeScript | Tipos protegem contra erros da IA |
| API | Node.js + Fastify | Leve e simples de testar |
| Banco | SQLite | Zero configuração para o MVP |
| Validação | Zod | Mesmos esquemas para tipos e validação |
| Frontend | React + Vite | Ecossistema amplo, bem conhecido pelos modelos |
| Testes | Vitest | Rápido e compatível com TypeScript |

Pode trocar, **desde que registre o porquê**.
