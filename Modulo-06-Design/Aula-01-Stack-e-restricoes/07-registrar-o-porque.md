# Registrar o porquê

Para cada escolha, três linhas:

```
Escolha: SQLite
Porque: MVP local, sem servidor, 1 usuário por vez.
Alternativas descartadas: PostgreSQL (infra extra sem necessidade agora).
```

Quando o porquê é registrado:

- outra pessoa (ou agente) não desfaz sem motivo;
- você sabe **quando** reavaliar (ex.: ao crescer).

Decisões importantes viram **ADR** (Módulo 10).
