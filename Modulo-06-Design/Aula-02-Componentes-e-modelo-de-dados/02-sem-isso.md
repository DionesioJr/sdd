# Os dados que mudam de forma

Sem modelo de dados definido:

- uma tarefa tem `prazo` num arquivo, `due_date` em outro e `vencimento` num terceiro;
- o status é texto livre: "feito", "concluída", "done";
- cada agente cria colunas conforme a necessidade do momento.

Corrigir isso depois significa **migrar dados** e mexer no sistema todo.
