# Do requisito ao dado

Cada campo existe por causa de um requisito.

| Campo | Vem de |
|---|---|
| `titulo` | RF-01 |
| `prazo` | RF-01 |
| `status` | RF-02, RF-03 |
| `concluidaEm` | critério de RF-03 |

Campo **sem requisito** é suspeito: ou falta requisito, ou o campo é desnecessário.
