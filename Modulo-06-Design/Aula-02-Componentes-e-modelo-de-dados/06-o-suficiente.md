# O suficiente para começar

Projetar demais é tão ruim quanto projetar de menos:

- **Modele o MVP**, e não o produto final.
- Deixe **pontos de extensão** óbvios, mas não os construa.
- Evite "e se um dia…" que a spec não pede.

Uma boa pergunta: *"se eu errar esta decisão, quanto custa corrigir?"* Quanto mais caro, mais vale pensar agora.
