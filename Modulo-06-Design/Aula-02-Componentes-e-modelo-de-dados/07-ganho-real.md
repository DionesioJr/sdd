# O ganho real

| Sem isso | Com isso |
|---|---|
| Campos com nomes diferentes | Um nome por conceito |
| Status em texto livre | Valores enumerados e validados |
| Regras de negócio espalhadas | Regras no domínio, testáveis |
| Migrar dados depois | Dados certos desde o começo |

**Ganho real**: o agente trabalha sobre uma estrutura estável, e os dados do usuário não precisam ser reescritos a cada tarefa.
