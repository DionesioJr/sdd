# Exercício 1: Dos requisitos aos dados

**Objetivo**: derivar o modelo de dados do seu `requirements.md`.

1. Releia os requisitos e liste os **substantivos** (tarefa, usuário, prazo…).
2. Defina as **entidades** do MVP e seus campos, com tipos e restrições.
3. Para cada campo, anote o **requisito** que o justifica.

**Observe**: algum requisito ficou sem dado que o atenda? Algum campo ficou sem requisito?

<!--
