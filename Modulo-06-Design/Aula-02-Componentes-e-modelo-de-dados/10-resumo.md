# Resumo

- Componentes têm **uma responsabilidade** e podem ser testados sozinhos.
- Dados: entidades, campos, tipos, restrições e valores enumerados.
- Cada campo vem de um requisito.
- Projete o suficiente para o MVP.

**O ganho real**: estrutura estável para o agente e menos migrações no futuro.

**Próxima aula**: os componentes precisam conversar. O **contrato de API** define essa conversa antes do código.
