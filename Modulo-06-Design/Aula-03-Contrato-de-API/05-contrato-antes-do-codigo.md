# O contrato antes do código

Quando o contrato existe antes:

- **Frontend e API** podem ser feitos em tarefas separadas (ou por agentes separados).
- O **teste** pode ser escrito a partir do contrato.
- Mudar o formato é editar **um** documento.

Se o código precisar de um endpoint novo, **o contrato muda primeiro** (a mesma regra da spec).
