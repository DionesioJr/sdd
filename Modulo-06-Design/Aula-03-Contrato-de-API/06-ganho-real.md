# O ganho real

| Sem isso | Com isso |
|---|---|
| Formatos diferentes em cada endpoint | Um contrato único |
| Front e back se desencontram | Combinados antes de existirem |
| Erros inconsistentes | Formato de erro padrão |
| Testes presos ao código | Testes derivados do contrato |

**Ganho real**: duas partes do sistema (ou dois agentes) podem avançar em paralelo sem se quebrarem.
