# Exercício 1: Desenhe o contrato

**Objetivo**: especificar os endpoints do MVP.

Para os requisitos RF-01 a RF-03, escreva em `docs/design.md`:

1. Método e caminho de cada endpoint.
2. Entrada e saída de sucesso (com exemplo JSON).
3. Erros possíveis, no formato padrão.
4. O RF que cada endpoint atende.

**Observe**: o que você precisou decidir (ex.: o que a listagem devolve quando não há tarefas)?
