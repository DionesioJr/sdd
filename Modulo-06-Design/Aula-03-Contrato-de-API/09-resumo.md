# Resumo

- O contrato define entrada, saída, erros e o requisito que atende.
- Erros seguem um formato único, com códigos estáveis.
- O contrato muda **antes** do código.
- Contrato claro permite trabalho em paralelo.

**O ganho real**: partes do sistema que não se quebram umas às outras.

**Próxima aula**: já temos as peças do design. Vamos organizá-las no **documento** e **aprová-lo** antes de codar.
