# O design que descreve o código

Equipes que "documentam o design" **depois** de codar produzem um espelho do código: ele descreve o que **foi** feito, não o que **deveria** ter sido.

- Não serve para revisar decisões (já é tarde).
- Não serve de contexto para o agente (o código já existe).
- Erros de design viram "o jeito que ficou".

O design só funciona como **decisão** quando vem **antes**.
