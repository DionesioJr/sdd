# O tamanho certo de uma tarefa

Uma boa tarefa:

1. tem **uma intenção** (uma frase a descreve);
2. mexe em **poucos arquivos**;
3. cabe numa **sessão curta**, sem estourar o contexto;
4. é **verificável**: há um teste ou comando que prova;
5. você **revisa em poucos minutos**.

Se você precisa de "e" para descrevê-la (*"criar o modelo **e** a API **e** a tela"*), são três tarefas.
