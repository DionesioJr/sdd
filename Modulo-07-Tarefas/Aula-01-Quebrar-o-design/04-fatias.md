# Fatias verticais

**Horizontal**: *"todo o banco, depois toda a API, depois toda a tela."* Nada funciona até o fim.

**Vertical**: *"criar tarefa de ponta a ponta (dado, API, tela)."* Cada fatia **funciona** sozinha.

Fluxo: Criar tarefa → Listar tarefas → Concluir tarefa → Filtrar

Prefira fatias verticais: você **vê** progresso real e valida cedo.
