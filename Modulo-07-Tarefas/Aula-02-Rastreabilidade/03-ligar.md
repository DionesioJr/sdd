# Cada tarefa aponta para a spec

```md
### T-03 Concluir tarefa (API + tela)
Atende: RF-03
Critérios: CA-03.1, CA-03.2
Depende de: T-01
```

- **Atende**: o requisito que a tarefa cumpre.
- **Critérios**: os critérios de aceite que ela precisa satisfazer.

A tarefa é **pronta** quando os critérios passam.
