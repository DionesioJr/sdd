# A IA confere a cobertura

```
Cruze requirements.md (apenas MVP) com tasks.md.
Gere uma tabela requisito → tarefas.
Liste:
1. requisitos do MVP sem tarefa;
2. tarefas sem requisito;
3. critérios de aceite que nenhuma tarefa cobre.
```

Confira cada achado: ela pode **errar** a ligação.

A rastreabilidade é o que permitirá, nos módulos finais, **uma IA revisar um PR contra a spec**.
