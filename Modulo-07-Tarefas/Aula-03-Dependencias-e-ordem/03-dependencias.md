# Dependências

Uma tarefa **depende** de outra quando precisa do resultado dela.

Ordem: T-01 Modelo → T-02 Criar → T-03 Listar → T-04 Concluir

```md
### T-03 Listar tarefas
Depende de: T-01, T-02
```

- Escreva **todas** as dependências diretas.
- **Sem ciclos**: se A depende de B e B de A, são a mesma tarefa, ou falta uma terceira.
