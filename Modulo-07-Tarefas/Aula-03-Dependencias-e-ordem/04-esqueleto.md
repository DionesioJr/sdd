# Comece por um esqueleto que anda

A **primeira fatia** deve atravessar o sistema inteiro, mesmo simples:

Esqueleto: Tela → API → Domínio → Banco

*Ex.: "criar uma tarefa só com título, ver na lista."*

Isso valida **a stack, o contrato e o ambiente** logo, enquanto mudar custa pouco.

Depois, cada tarefa **engorda** o esqueleto.
