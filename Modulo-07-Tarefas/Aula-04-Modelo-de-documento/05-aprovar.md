# O terceiro portão

**Checklist de aprovação do plano**:

1. Todos os RF do MVP têm tarefa (cobertura).
2. Toda tarefa cita requisito e critérios.
3. Dependências sem ciclos; esqueleto primeiro.
4. Cada tarefa passa nos 5 critérios de tamanho.
5. Uma pessoa **leu e aprovou**.

Se aprovada, a lista **vira o roteiro de implementação**.
