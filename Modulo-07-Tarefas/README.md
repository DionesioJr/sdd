# Módulo 07: Tarefas

Objetivo: transformar spec e design em uma lista de tarefas pequenas, rastreáveis e ordenadas, que o agente consiga executar e acertar de primeira.

## Por que este módulo existe

Com Product Spec e Design aprovados, a tentação é pedir *"implemente tudo"*. É aqui que muita gente desiste do método: o agente se perde, mistura assuntos e entrega algo grande demais para revisar.

**Sem este módulo**: um pedido enorme gera um diff impossível de ler. Você aceita sem entender (o erro do Módulo 03) ou descarta tudo.

**Ganho real**: tarefas do tamanho certo, cada uma ligada ao requisito que atende, na ordem que faz sentido. O agente acerta mais, e você consegue revisar cada entrega em minutos.
