# O ciclo da tarefa

Ciclo: Branch → Plano → Código → Teste → Revisão → Commit

1. **Branch**: uma por tarefa (`git switch -c t-03-concluir`).
2. **Plano**: o agente propõe os passos; você aprova.
3. **Código**: uma etapa por vez.
4. **Teste**: rode a verificação do Taskfile.
5. **Revisão**: leia o `git diff` com o roteiro do Módulo 03.
6. **Commit**: mensagem que cita o requisito.
