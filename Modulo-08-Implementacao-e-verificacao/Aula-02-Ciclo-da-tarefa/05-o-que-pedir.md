# O pedido de cada tarefa

```
Execute a tarefa em docs/taskfiles/T-03.md.
1. Leia apenas o que ela pede.
2. Proponha um plano curto e espere minha aprovação.
3. Implemente por etapas, rodando a verificação em cada uma.
4. Não altere arquivos fora do escopo.
```

O pedido é sempre **o mesmo**: o que muda é o Taskfile. Padronizar também reduz o seu esforço.
