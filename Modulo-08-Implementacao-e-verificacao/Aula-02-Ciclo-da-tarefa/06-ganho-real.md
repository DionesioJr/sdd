# O ganho real

| Sem isso | Com isso |
|---|---|
| Um commit gigante | Um commit por tarefa |
| Bug sem origem conhecida | Bug localizado em uma tarefa |
| Desfazer perde tudo | `git revert` de uma tarefa |
| Progresso invisível | Checkboxes e histórico |

**Ganho real**: erros se isolam, o histórico conta a história do projeto e você mantém o controle em cada passo.
