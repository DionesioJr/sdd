# Aula 03: Testes a partir dos critérios

**Módulo 08 · Implementação e verificação**

Ao final desta aula você vai saber:

- transformar cada critério de aceite num teste;
- pedir os testes **antes** do código;
- evitar testes que só repetem o código.
