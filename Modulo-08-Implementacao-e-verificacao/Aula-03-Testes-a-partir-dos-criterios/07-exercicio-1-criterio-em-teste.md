# Exercício 1: Do critério ao teste

**Objetivo**: traduzir sem ajuda.

Para o critério:

```
Se o título estiver vazio, então o sistema deve recusar a tarefa
e exibir "Título é obrigatório".
```

1. Escreva (à mão) o teste em TypeScript (Vitest).
2. Identifique **Dado, Quando, Então** no teste.
3. Dê ao teste um nome que cite o critério.

**Observe**: o que você precisou decidir que o critério não dizia?
