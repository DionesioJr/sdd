# Resumo

- Cada critério vira um teste, com nome que cita o critério.
- Testes **antes** do código: precisam falhar primeiro.
- O agente não altera testes para fazê-los passar.
- Pergunta de controle: se eu quebrar o código, o teste falha?

**O ganho real**: teste verde significa "cumpre a spec".

**Próxima aula**: mesmo com tudo isso, o agente vai **errar**. Quando isso ocorrer, **onde está a causa**?
