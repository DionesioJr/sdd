# Exercício 1: Valide o MVP

**Objetivo**: provar o que foi entregue.

1. Monte a tabela **critério, teste, resultado** para todo o MVP.
2. Rode a suíte de testes e a verificação de tipos.
3. Para critérios sem teste, verifique à mão e registre.
4. Abra uma **tarefa nova** para cada falha.

**Observe**: quantos critérios não tinham teste automático? O que isso indica?
