# Cinco sinais

### 1. Tamanho

Mais de algumas centenas de linhas por arquivo.

### 2. Vários domínios

O mesmo arquivo trata de assuntos que não se misturam.

### 3. Vários autores

Conflitos de edição e revisão pesada.

### 4. Contexto inchado

O agente recebe muito texto para uma tarefa pequena.

### 5. Contradições

Regras que se desmentem sem ninguém notar.
