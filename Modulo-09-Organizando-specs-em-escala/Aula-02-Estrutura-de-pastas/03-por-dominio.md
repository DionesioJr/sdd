# Divida por domínio

**Domínio**: uma área do negócio com regras próprias.

```
docs/
├── product/
│   ├── 00-visao.md        ← visão geral e índice
│   ├── tarefas.md
│   ├── equipes.md
│   ├── notificacoes.md
│   └── relatorios.md
├── architecture/
├── tasks/
└── guidelines/
```

Cada domínio tem **seu arquivo** (ou pasta, se crescer). As regras vivem num lugar só.
