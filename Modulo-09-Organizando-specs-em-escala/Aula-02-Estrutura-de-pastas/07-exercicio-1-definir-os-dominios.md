# Exercício 1: Defina os domínios

**Objetivo**: decidir as fronteiras antes de mover arquivos.

1. Liste as capacidades do gestor (tarefas, equipes, notificações, relatórios…).
2. Agrupe por **regras que mudam juntas**.
3. Para cada domínio, escreva uma frase: *"Este domínio cuida de…"*
4. Aponte as **relações** (ex.: Tarefa pertence a uma Equipe).

**Observe**: alguma capacidade ficou entre dois domínios? Como você decidiu?
