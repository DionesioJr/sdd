# IDs com prefixo de domínio

```
TAR-RF-01   Criar tarefa
TAR-RF-02   Listar tarefas
EQP-RF-01   Criar equipe
EQP-RF-02   Convidar membro
NOT-RF-01   Notificar prazo próximo
```

- O **prefixo** identifica o domínio.
- O **número** nunca é reaproveitado, mesmo se o requisito for removido.
- Referências antigas continuam válidas.

Um ID é um **endereço permanente**. Trate-o assim.
