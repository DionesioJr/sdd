# Numerar para ordenar

```
tasks/
└── epic-01-equipes/
    ├── 01-modelo-de-dados.md
    ├── 02-api-de-convites.md
    └── 03-tela-de-membros.md
```

- O **número** define a **ordem de execução** (e aparece sempre na listagem).
- Dois dígitos permitem até 99 por pasta.
- O **nome** descreve a tarefa em poucas palavras.

Numeração de **arquivo** é ordem; ID de **requisito** é identidade.

<!--
Não confundir os dois: o número do arquivo pode mudar se a ordem mudar; o ID do requisito, nunca.
