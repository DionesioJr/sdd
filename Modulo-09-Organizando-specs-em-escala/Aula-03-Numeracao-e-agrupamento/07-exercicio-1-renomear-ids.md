# Exercício 1: Prefixos de ID

**Objetivo**: migrar os IDs com segurança.

1. Escolha o prefixo de cada domínio (3 letras).
2. Renomeie os requisitos do MVP: `RF-01` → `TAR-RF-01`.
3. Peça à IA para listar **todos** os lugares que citam os IDs antigos (spec, tarefas, testes, commits).
4. Atualize **cada um** e confira com `git grep "RF-"`.

**Observe**: o que você esqueceu sem a busca?
