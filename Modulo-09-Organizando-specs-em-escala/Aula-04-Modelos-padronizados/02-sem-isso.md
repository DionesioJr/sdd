# Cada autor, um formato

Três pessoas (e dois agentes) escrevem documentos:

- uma começa pelos critérios; outra, pelo problema;
- uma esquece de escrever "fora do escopo";
- o agente cria arquivos com cabeçalhos próprios.

Para revisar, é preciso **descobrir a estrutura** de cada um. Para o agente ler, é preciso adivinhar onde está a informação.
