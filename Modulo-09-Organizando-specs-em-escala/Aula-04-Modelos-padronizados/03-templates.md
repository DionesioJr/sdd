# Um modelo por tipo de documento

```
docs/_modelos/
├── dominio-produto.md
├── design-de-modulo.md
├── adr.md
├── epico.md
├── tarefa.md
└── taskfile.md
```

Cada modelo traz:

- as **seções** na ordem certa;
- uma **instrução** do que escrever em cada uma;
- um **exemplo curto**.

Os modelos que você já criou nos Módulos 05 a 08 viram a base.
