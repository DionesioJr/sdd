# Pedir documentos com o modelo

```
Crie docs/product/notificacoes.md usando docs/_modelos/dominio-produto.md.
Prefixo: NOT.
Requisitos: avisar o usuário 24h antes do prazo; permitir desligar.
Preencha todas as seções. Onde faltar informação,
registre em "Perguntas em aberto" e NÃO invente.
```

O modelo **reduz o que o agente precisa decidir** e torna a revisão rápida.
