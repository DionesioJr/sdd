# Exercício 1: Crie os modelos

**Objetivo**: montar `docs/_modelos/`.

1. Crie um modelo para **cada** tipo: domínio, design de módulo, ADR, épico, tarefa e Taskfile.
2. Em cada um, escreva seções, instruções e um exemplo curto.
3. Use como base os documentos aprovados do MVP.

**Observe**: que seções você tornou obrigatórias? Por quê?
