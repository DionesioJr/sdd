# Auditoria com a IA

```
Leia docs/glossario.md e todos os arquivos em docs/product/.
Liste:
1. termos usados que não estão no glossário;
2. sinônimos para o mesmo conceito;
3. o mesmo termo usado com sentidos diferentes.
NÃO altere arquivos. Cite arquivo e trecho.
```

Faça a mesma auditoria no **código**: `git grep -i "grupo\|time"` revela nomes divergentes.

A IA **aponta**; você escolhe o termo oficial e o glossário muda **primeiro**.
