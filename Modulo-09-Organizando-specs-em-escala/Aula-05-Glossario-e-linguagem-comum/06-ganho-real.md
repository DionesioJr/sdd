# O ganho real

| Sem isso | Com isso |
|---|---|
| Quatro nomes para a mesma coisa | Um nome, em todo lugar |
| O agente cria estruturas duplicadas | O agente usa o vocabulário certo |
| Discussões de significado | O glossário responde |
| Novos membros se confundem | Vocabulário aprendido em minutos |

**Ganho real**: menos erros de interpretação, menos duplicação de código e uma equipe (e um agente) que se entendem.
