# No repositório ou numa ferramenta?

| | No repositório | Em ferramenta (Notion, Confluence…) |
|---|---|---|
| Versão e histórico | Git, completo | Histórico próprio |
| Revisão | Pull Request | Comentários |
| Lido pelo agente | Direto, como arquivo | Via integração ou cópia |
| Quem edita | Quem usa Git | Qualquer pessoa |

Para SDD com agentes: **o repositório é a fonte** (o agente lê, a IA e o CI podem checar). Ferramentas externas podem **espelhar**, não **mandar**.
