# Exercício 1: Um PR de spec

**Objetivo**: mudar a spec com controle.

1. Crie a branch `spec/notificacoes-lembrete`.
2. Altere um requisito em `notificacoes.md` (ex.: lembrete 48h antes).
3. Atualize versão e histórico.
4. Abra um PR (ou faça a revisão por diff, se não usar GitHub) e **aprove**.

**Observe**: o que a revisão pegou antes do merge?
