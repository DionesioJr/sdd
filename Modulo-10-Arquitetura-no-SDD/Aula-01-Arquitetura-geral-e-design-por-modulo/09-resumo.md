# Resumo

- Arquitetura geral: vale para o sistema todo, muda raramente.
- Design de módulo: vale para um módulo, muda com as features.
- Se vale para mais de um módulo, sobe.
- Cada módulo de design tem o nome do domínio de produto.

**O ganho real**: contexto menor e mudanças globais deliberadas.

**Próxima aula**: decisões globais precisam de **registro** para não serem desfeitas. Vamos escrever **ADRs**.
