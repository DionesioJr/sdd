# Um ADR completo

```md
# 0002: Monolito modular
Status: Aceito · 2026-11-03

## Contexto
Time de uma pessoa, domínios ainda mudam muito, prazos curtos.

## Decisão
Um único processo, com módulos separados por pasta.

## Alternativas
- Microsserviços: custo operacional sem necessidade agora.

## Consequências
+ Deploy simples, testes rápidos.
- Se um módulo precisar escalar sozinho, será preciso extraí-lo.
```

**Curto e específico.** Meia página basta.
