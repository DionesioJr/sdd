# O ganho real

| Sem isso | Com isso |
|---|---|
| Qualquer coisa importa qualquer coisa | Importa só da interface pública |
| Mudança interna quebra os outros | Mudança interna é segura |
| Uma tarefa atravessa o sistema | Uma tarefa toca um módulo |
| Fronteira por confiança | Fronteira verificada por ferramenta |

**Ganho real**: cada tarefa fica **isolada** a uma parte do sistema, e erros do agente não se espalham.
