# O mesmo erro, toda sessão

Toda sessão nova, o agente:

- roda os testes com o comando errado;
- usa `moment` em vez de `date-fns`;
- cria uma pasta `utils/`.

Você corrige. Na sessão seguinte, **de novo**. O modelo não lembra (Módulo 01).

A alternativa ruim: um `AGENTS.md` de 800 linhas que copia a spec. Agora o agente lê tudo, **toda vez**, e continua errando.
