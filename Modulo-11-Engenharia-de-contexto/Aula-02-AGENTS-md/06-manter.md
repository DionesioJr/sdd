# Como mantê-lo

Cada erro **recorrente** do agente vira **uma linha**.

Fluxo: Erro repetido → Diagnóstico (Módulo 08) → Uma linha no AGENTS.md → Erro some

E, ao contrário, **remova** linhas que:

- o linter agora garante;
- ninguém mais precisa;
- viraram guideline (próxima aula).

Revise o arquivo a cada sprint. Um `AGENTS.md` que só cresce é o sinal de problema.
