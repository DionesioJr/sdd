# O ganho real

| Sem isso | Com isso |
|---|---|
| O agente repete erros em toda sessão | O erro corrigido não volta |
| Regras só na cabeça de quem sabe | Regras escritas para pessoas e agentes |
| Arquivo gigante que ninguém lê | Arquivo curto, de alto sinal |
| Cada sessão começa do zero | Cada sessão começa informada |

**Ganho real**: o que você ensinou **uma vez** vale para **toda** sessão, e o custo fixo continua baixo.
