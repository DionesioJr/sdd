# Exercício 1: Escreva o `AGENTS.md`

**Objetivo**: criar o arquivo a partir de evidências.

1. Liste os **erros recorrentes** que o agente cometeu no gestor (use as notas dos Módulos 08 a 10).
2. Escreva `AGENTS.md` na raiz com: comandos, regras, ponteiros.
3. Para cada linha, anote **o erro que ela evita**.
4. Conte as linhas: meta, **menos de 60**.

**Observe**: que linhas você cortou por não passar no teste "se eu apagar, o agente erra?"
