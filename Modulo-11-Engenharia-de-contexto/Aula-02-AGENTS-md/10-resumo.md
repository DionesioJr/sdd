# Resumo

- `AGENTS.md`: regras fixas, lidas em toda sessão.
- Entra o que o agente erraria sem; fica de fora o que se aponta.
- Cada erro recorrente vira uma linha; o que não serve mais sai.
- Curto, e revisado a cada sprint.

**O ganho real**: o que você ensinou uma vez vale sempre.

**Próxima aula**: nem toda regra vale para toda tarefa. **Guidelines** guardam convenções que só carregam quando precisam.
