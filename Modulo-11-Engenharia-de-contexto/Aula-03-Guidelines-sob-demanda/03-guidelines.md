# Uma guideline por assunto

```
docs/guidelines/
├── testes.md
├── api.md
├── frontend.md
├── erros-e-logs.md
└── git-e-commits.md
```

Cada uma traz as convenções **de um assunto**: regras, exemplo certo e exemplo errado.

No `AGENTS.md`, só **quando ler**:

```md
- Ao criar ou alterar testes: leia `docs/guidelines/testes.md`.
- Ao criar endpoints: leia `docs/guidelines/api.md`.
```
