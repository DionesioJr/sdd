# O prompt de trinta linhas, colado quinze vezes

Toda vez que precisa criar um endpoint, você cola o mesmo pedido: estrutura de pastas, validação, teste, atualização do contrato, glossário.

- Cada cópia pode sair um pouco diferente.
- Você esquece um passo (o teste, o contrato).
- Quem entra no time nem sabe que o pedido existe.
