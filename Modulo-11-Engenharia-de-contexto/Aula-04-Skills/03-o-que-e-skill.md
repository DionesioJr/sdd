# O que é uma skill

Um **procedimento empacotado**: instruções passo a passo (e arquivos de apoio) que o agente carrega **quando a tarefa pede**.

- No contexto fica **só a descrição** (uma ou duas linhas).
- O texto completo é carregado **quando a skill é usada**.
- No Pi, são chamadas com `/skill:nome`, ou o agente as escolhe pela descrição.

**Guideline** diz *como é*; **skill** diz *como fazer*.
