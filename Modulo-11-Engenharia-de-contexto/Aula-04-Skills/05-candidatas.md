# O que virar skill

| Procedimento | Skill |
|---|---|
| Criar um endpoint | `criar-endpoint` |
| Transformar critérios em testes | `criar-testes-do-criterio` |
| Criar spec de um domínio novo | `criar-spec-de-dominio` |
| Escrever um ADR | `criar-adr` |
| Revisar um diff contra a spec | `revisar-contra-a-spec` |

Critério: o procedimento é **repetido**, tem **passos fixos** e já deu **erro por esquecimento**.
