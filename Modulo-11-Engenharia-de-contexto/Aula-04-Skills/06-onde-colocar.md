# Onde colocar cada coisa

| Informação | Onde |
|---|---|
| Vale em **toda** sessão e é curta | `AGENTS.md` |
| Convenção que vale por **assunto** | Guideline |
| Procedimento com **passos** | Skill |
| Vale só para **esta tarefa** | Taskfile |
| Decisão e seu motivo | ADR |
| O que o sistema **faz** | Spec |

Dúvida comum: se tem passos, é skill; se é regra, é guideline.
