# Exercício 1: Crie uma skill

**Objetivo**: empacotar um procedimento real.

1. Escolha o procedimento que você mais repetiu (ex.: criar endpoint).
2. Escreva a skill (`SKILL.md`) com **nome**, **descrição pelo quando usar** e **passos**.
3. Inclua o arquivo de referência e os comandos de verificação.

**Observe**: que passos você descobriu que costumava esquecer?
