# O ganho real

| Sem isso | Com isso |
|---|---|
| Contexto no chute | Contexto por regra |
| Resultado depende de quem pediu | Resultado repetível |
| Esquecimentos (ADR, guideline) | Lista que garante |
| Impossível automatizar | Pronto para a esteira de agentes |

**Ganho real**: cada tarefa recebe o contexto certo, **sempre**, o que torna o resultado previsível e abre caminho para a automação.
