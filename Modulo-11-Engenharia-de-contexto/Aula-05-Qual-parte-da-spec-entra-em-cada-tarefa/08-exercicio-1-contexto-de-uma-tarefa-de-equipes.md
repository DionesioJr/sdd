# Exercício 1: Contexto de uma tarefa

**Objetivo**: montar o Taskfile com contexto certo.

1. Escolha a tarefa **API de convites** (ou a próxima de Equipes).
2. Preencha **Ler antes** (em ordem), **Não ler** e **Pronto quando**.
3. Para cada item, justifique: *"se eu tirar, o agente erra?"*

**Observe**: o que você quase esqueceu de incluir? E o que quase incluiu sem precisar?
