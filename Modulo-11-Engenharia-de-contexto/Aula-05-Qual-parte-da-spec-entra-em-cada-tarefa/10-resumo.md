# Resumo

- Cada tarefa tem um mapa: requisito, módulo, ADRs, guideline, glossário, exemplo.
- O Taskfile é uma receita de contexto, com "ler antes" e "não ler".
- A cobaia valida; o Taskfile pode ser gerado.
- Rastreabilidade viabiliza automação.

**O ganho real**: contexto certo, sempre.

**Próximo módulo**: o agente tem o contexto certo. Como saber se o que ele entrega está **correto**? **Testes como contrato**.
