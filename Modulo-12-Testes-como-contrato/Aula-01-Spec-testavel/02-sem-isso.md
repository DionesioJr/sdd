# O requisito que ninguém consegue testar

*"As notificações devem chegar na hora certa."*

- Qual é a hora certa?
- Como o teste sabe que "chegou"?
- Como testar sem esperar 24 horas?

O agente escreve um teste que passa sempre, ou nenhum teste. A spec **não é testável**, então o código nunca será verificado.
