# O ganho real

| Sem isso | Com isso |
|---|---|
| Requisitos que nenhum teste verifica | Todo requisito tem casos |
| Código preso ao relógio e ao banco | Código com dependências injetadas |
| Bugs nos limites | Limites testados |
| "Como testar isso?" na hora de codar | A pergunta é respondida no design |

**Ganho real**: a spec passa a ser **verificável de verdade**, e o código nasce testável.
