# Exercício 1: Reescreva para testar

**Objetivo**: tornar requisitos testáveis.

Reescreva cada requisito de forma testável:

1. *"As tarefas atrasadas aparecem em destaque."*
2. *"O relatório mostra a produtividade da equipe."*
3. *"O sistema envia lembretes no momento adequado."*

Para cada um, liste **três casos** de teste.

**Observe**: que definição você precisou criar (o que é "produtividade"?)
