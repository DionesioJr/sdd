# Resumo

- Requisito testável: entrada, resultado observável, determinismo e limites.
- Tempo, aleatoriedade e banco entram como **parâmetros**.
- Um critério gera vários casos, principalmente nos limites.
- Testabilidade é decisão de design.

**O ganho real**: a spec é verificável e o código nasce testável.

**Próxima aula**: requisitos testáveis em mãos, é hora de pedir os **testes** à IA, **sem** que eles mintam.
