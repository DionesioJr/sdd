# Pedir testes que não mentem

```
Escreva testes para os critérios TAR-RF-03.1 e TAR-RF-03.2.
- Um teste por critério, com o ID no nome.
- Teste o comportamento, não a implementação.
- Não use mocks para o que está sendo testado.
- Use o banco SQLite em memória nos testes de integração.
- Inclua limites e erros.
- NÃO altere o código. Rode e mostre que falham.
```

Os testes vêm **dos critérios** (Módulo 08), e não do código que já existe.
