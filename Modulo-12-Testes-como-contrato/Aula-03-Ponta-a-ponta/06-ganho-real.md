# O ganho real

| Sem isso | Com isso |
|---|---|
| Peças corretas, fluxo quebrado | O fluxo do usuário é provado |
| Regressões visíveis só ao usuário | Detectadas antes da entrega |
| Frontend e backend desencontrados | O E2E pega o desencontro |
| Medo de mexer na tela | Rede de segurança no fluxo principal |

**Ganho real**: o que a Product Spec promete ao usuário é **verificado**, e não suposto.
