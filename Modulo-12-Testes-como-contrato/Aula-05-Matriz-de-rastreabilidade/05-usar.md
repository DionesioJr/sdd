# Para que serve

- **Achar lacunas**: critérios sem teste viram tarefas.
- **Achar extras**: testes sem critério (testam algo que a spec não pede).
- **Provar cobertura** em auditorias e entregas.
- **Falhar o pipeline** se um critério do MVP ficar sem teste (Módulo 16).
- **Guiar a IA**: *"escreva os testes dos critérios sem teste na matriz."*

A matriz fecha o ciclo da **rastreabilidade**: requisito → critério → teste → commit.
