# Exercício 1: O script da matriz

**Objetivo**: gerar a matriz do gestor.

1. Garanta que os testes citam o ID do critério no nome.
2. Peça ao agente o script `npm run matriz`.
3. Revise a lógica: ele lê as specs? Lê os testes? Cruza?
4. Rode e leia `docs/qualidade/matriz.md`.

**Observe**: quantos critérios estão **sem teste**?
