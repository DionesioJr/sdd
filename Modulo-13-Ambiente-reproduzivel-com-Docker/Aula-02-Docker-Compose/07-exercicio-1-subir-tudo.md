# Exercício 1: Suba tudo

**Objetivo**: ter o gestor e o serviço de e-mail rodando.

1. Escreva o `compose.yaml` com a API e o Mailpit.
2. Crie `.env.example` e `.env` (valores falsos).
3. Rode `docker compose up --build`.
4. Dispare uma notificação do gestor e veja o e-mail no painel (`localhost:8025`).

**Observe**: quanto tempo leva do clone ao sistema funcionando?
