# Resumo

- O Compose descreve vários serviços num arquivo.
- Um comando sobe o ambiente; `down -v` o reinicia limpo.
- Volumes guardam dados; redes ligam serviços; healthchecks dizem quando está pronto.
- `.env.example` no repositório; `.env` fora.

**O ganho real**: sistema completo idêntico para todos.

**Próxima aula**: o ambiente existe. Falta **garantir que todos o usem**: pessoa, agente e CI, **o mesmo**.
