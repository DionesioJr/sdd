# Exercício 2: Reproduza uma falha

**Objetivo**: usar o ambiente para depurar.

1. Provoque uma falha que dependa do ambiente (ex.: uma variável obrigatória ausente no `.env.example`).
2. Rode `npm run test:docker` e observe.
3. Entregue o log ao agente com: *"Reproduza e corrija."*
