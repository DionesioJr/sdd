# Resumo

- Um comando por tarefa (dev, teste, E2E, fronteiras), sempre via container.
- O `AGENTS.md` manda o agente usar esses comandos.
- O que o agente instala fica no container.
- Falha do CI se reproduz com o mesmo comando.

**O ganho real**: "passou" significa o mesmo em todo lugar.

**Próximo módulo (Nível 4)**: o projeto está no ar, é grande e **vivo**. Raramente se começa do zero: **estratégias** para features, bugs, refatorações e sistemas existentes.
