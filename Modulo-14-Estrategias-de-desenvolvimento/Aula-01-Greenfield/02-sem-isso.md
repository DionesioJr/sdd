# Começar do zero é a parte perigosa

Como não há código nem restrições, a tentação é correr:

- começar a codar no primeiro dia ("depois documentamos");
- escolher a stack pela moda;
- copiar a arquitetura de outro projeto sem entender o problema.

Seis meses depois, o projeto **parece** novo, mas já carrega decisões que ninguém lembra de ter tomado.
