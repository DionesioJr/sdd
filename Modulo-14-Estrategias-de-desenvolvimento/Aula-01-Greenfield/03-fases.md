# Greenfield: todas as fases

Ideia → Product Spec → Design → Tarefas → Implementação → Verificação → Entrega

| Fase | Entrega |
|---|---|
| Especificar | Problema, requisitos, critérios, MVP |
| Projetar | Stack, componentes, dados, contratos, ADRs |
| Tarefas | Plano rastreável, esqueleto primeiro |
| Implementar | Taskfile por tarefa, commits pequenos |
| Verificar | Testes dos critérios, validação do MVP |
| Entregar | Ambiente reproduzível, CI/CD |

É o que você fez nos Módulos 05 a 08, agora com os **Módulos 09 a 13** como alicerce desde o início.
