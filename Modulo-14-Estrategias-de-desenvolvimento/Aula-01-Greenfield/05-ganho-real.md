# O ganho real

| Sem isso | Com isso |
|---|---|
| Codar primeiro, documentar nunca | Spec e design como ponto de partida |
| Decisões implícitas | ADRs desde o início |
| Estrutura improvisada | Esqueleto com testes e ambiente |
| Spec enorme antes de validar | Spec do MVP, validada rápido |

**Ganho real**: o projeto nasce com a base que os outros módulos mostraram ser necessária, sem o custo de arrumar depois.
