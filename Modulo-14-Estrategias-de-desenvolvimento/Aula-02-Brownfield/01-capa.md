# Aula 02: Brownfield

**Módulo 14 · Estratégias de desenvolvimento**

Ao final desta aula você vai saber:

- por que não se deve especificar um sistema existente como se fosse novo;
- analisar um código existente e gerar uma **spec reversa**;
- escrever uma nova spec que respeita o que já existe.
