# O fluxo brownfield

Sistema existente → Análise → Spec reversa → Nova spec → Código

1. **Análise**: entender o que o sistema faz, hoje.
2. **Spec reversa**: documentar o comportamento atual.
3. **Nova spec**: o que será mudado, **respeitando** o existente.
4. **Código**: a mudança, com testes que **preservam** o resto.

Você **não** parte da ideia: parte da **realidade**.
