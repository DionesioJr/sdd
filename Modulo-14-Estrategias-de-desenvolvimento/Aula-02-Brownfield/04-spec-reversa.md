# Spec reversa com a IA

```
Analise o módulo src/legado/cobranca.
Gere uma spec reversa:
- o que o módulo faz (comportamento observável);
- regras de negócio que encontrar no código;
- entradas, saídas e erros;
- dependências e efeitos colaterais;
- pontos que você NÃO conseguiu entender (liste como perguntas).
Cite arquivo e linha. NÃO altere nada.
```

**Cuidado**: a IA descreve o que o código **faz**, não o que ele **deveria** fazer, e pode **errar**. Confira os trechos críticos executando o código.
