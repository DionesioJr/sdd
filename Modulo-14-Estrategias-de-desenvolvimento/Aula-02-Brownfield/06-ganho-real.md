# O ganho real

| Sem isso | Com isso |
|---|---|
| O agente muda sem entender | Spec reversa como contexto |
| Regras escondidas quebradas | Regras documentadas e travadas por testes |
| Padrões que divergem | A nova spec respeita o existente |
| Medo de tocar no legado | Rede de segurança de testes |

**Ganho real**: dá para evoluir um sistema antigo **com** agente, sem aposta.
