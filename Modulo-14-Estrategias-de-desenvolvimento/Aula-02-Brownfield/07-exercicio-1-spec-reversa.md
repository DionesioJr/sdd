# Exercício 1: Sua primeira spec reversa

**Objetivo**: documentar um código sem documentação.

1. Em **uma branch**, apague a pasta `docs/` do gestor (fica o código e os testes).
2. Em sessão nova, peça a spec reversa do módulo **Tarefas** (pedido do slide).
3. Compare com a Product Spec original.

**Observe**: o que a spec reversa **capturou** (comportamento)? O que **não** capturou (intenção, motivos, o que ficou de fora)?
