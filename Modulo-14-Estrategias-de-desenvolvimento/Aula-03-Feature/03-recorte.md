# O recorte da feature

Fluxo: Requisitos da feature → Design dos componentes afetados → Tarefas → Código

- **Requisitos**: só da feature (novos RF e critérios), no domínio certo.
- **Design**: só dos módulos **afetados**; o resto, nem se abre.
- **Tarefas**: poucas, rastreáveis aos novos RF.
- **ADR**: só se a feature exigir decisão de arquitetura.

Uma feature pequena cabe em **uma página**: o "mini-spec".
