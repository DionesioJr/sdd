# Analise o impacto antes de especificar

Pergunte (ou peça ao agente, e confira):

1. **Quais módulos** a feature toca? (Fronteiras do Módulo 10.)
2. **Que dados** muda ou cria? (Migração?)
3. **Que contratos** de API muda? (Compatibilidade?)
4. **Que requisitos existentes** podem ser afetados?
5. **Que testes** precisam mudar?

Se a feature toca **muitos** módulos, talvez seja **várias** features.
