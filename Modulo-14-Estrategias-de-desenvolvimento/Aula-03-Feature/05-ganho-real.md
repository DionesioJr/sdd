# O ganho real

| Sem isso | Com isso |
|---|---|
| Burocracia desproporcional | Mini-spec proporcional |
| Improviso sem registro | Requisitos e critérios da feature |
| Impacto descoberto no código | Impacto analisado antes |
| Spec que não acompanha | Spec atualizada com a feature |

**Ganho real**: features entregues **rápido** e **com registro**: o método encolhe à medida da mudança.
