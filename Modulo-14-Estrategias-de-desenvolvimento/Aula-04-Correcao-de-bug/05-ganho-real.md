# O ganho real

| Sem isso | Com isso |
|---|---|
| "Corrigido" sem prova | Teste que falha e passa |
| O bug volta numa refatoração | O teste o impede |
| A causa permanece obscura | Causa registrada |
| A spec continua com a lacuna | A spec é atualizada |

**Ganho real**: cada bug corrigido **melhora o projeto de forma permanente**, e o mesmo bug não aparece duas vezes.
