# "Só uma arrumada rápida"

Você pede ao agente: *"refatore o módulo de relatórios para ficar mais limpo."*

Ele reescreve, troca nomes, muda a ordem de campos no resultado e, no caminho, **altera um comportamento** sem avisar.

Os testes (poucos) passam. Três dias depois, um relatório sai diferente.

- O que era para **melhorar**?
- O que **não** podia mudar?
