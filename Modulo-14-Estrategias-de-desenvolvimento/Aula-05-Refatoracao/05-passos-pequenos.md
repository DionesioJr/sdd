# Passos pequenos, sempre verdes

Fluxo: Testes verdes → Um passo → Testes verdes → Commit → Próximo passo

- Cada passo é **pequeno** e termina com os testes **verdes**.
- Um commit por passo: qualquer um pode ser desfeito.
- O **teste de mutação** (Módulo 12) mostra se a rede é forte o bastante.

Peça: *"Faça apenas o primeiro passo do plano e pare."*
