# A PoC que foi para produção

Numa tarde, o agente montou uma integração com um calendário externo. Funcionou na demo.

Ninguém quis refazer. A PoC foi para produção:

- sem testes;
- sem tratamento de erros;
- com segredos no código;
- ninguém sabe como ela funciona.

Seis meses depois, é o ponto mais frágil do sistema.
