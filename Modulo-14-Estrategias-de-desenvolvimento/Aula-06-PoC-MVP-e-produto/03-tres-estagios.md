# Três estágios

| | Pergunta | Código | Spec |
|---|---|---|---|
| **PoC** | É possível? | Descartável | Só a pergunta e o critério de sucesso |
| **MVP** | O usuário quer? | Evolui | Completa para o essencial |
| **Produto** | Funciona bem, sempre? | Robusto | Completa, versionada |

Fluxo: PoC → Decisão → MVP → Produto

Entre PoC e MVP há uma **decisão consciente**: seguir ou parar.
