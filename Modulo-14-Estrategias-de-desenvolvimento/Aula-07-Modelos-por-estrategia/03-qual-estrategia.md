# Qual estratégia usar

| Situação | Estratégia | Documentos |
|---|---|---|
| Projeto novo | Greenfield | Spec, design, ADRs, tarefas |
| Sistema sem documentação | Brownfield | Spec reversa, testes de caracterização, nova spec |
| Funcionalidade nova | Feature | Mini-spec, design delta |
| Defeito | Bug | Relato, teste que falha, critério |
| Melhoria interna | Refatoração | Melhora e "não pode mudar" |
| Ideia incerta | PoC | Pergunta, critério, relatório |

Uma pergunta decide: **"o que está mudando, e qual o risco?"**
