# Resumo

- O agente tem as suas permissões: o erro ou engano dele vale o que você pode.
- Menor privilégio: container, usuário limitado, sem credenciais de produção, rede restrita.
- Injeção de prompt: texto externo vira instrução.
- Defesa: contenção, revisão de comandos, aprovação para o que é de risco.

**O ganho real**: pior caso contido.

**Próxima aula**: a segurança do sistema também é **requisito**. Como escrevê-lo para ser **verificável**?
