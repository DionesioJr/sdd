# O ganho real

| Sem isso | Com isso |
|---|---|
| Verificação por memória | Verificação automática |
| Suíte quebrada na `main` | `main` sempre verde |
| Segredo e violações entram | Barrados no PR |
| "Quem rodou?" sem resposta | Cada PR tem um registro |

**Ganho real**: a qualidade deixa de depender de lembrar, e **cada PR do agente passa pelo mesmo funil** que o de uma pessoa.
