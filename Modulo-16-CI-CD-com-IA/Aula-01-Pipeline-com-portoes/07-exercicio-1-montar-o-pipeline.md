# Exercício 1: Monte o pipeline

**Objetivo**: automatizar as verificações do gestor.

1. Crie o workflow de CI com tipos, testes, fronteiras, matriz e auditoria.
2. Abra um PR e veja o pipeline rodar.
3. Habilite a **proteção da branch** `main` exigindo o pipeline verde.

**Observe**: qual etapa é a mais lenta? A ordem poderia ser melhor?
