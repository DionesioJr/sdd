# O template de PR

```md
## O que entrega
<uma frase>

## Requisitos e tarefa
- Tarefa: EQP-T-02
- Requisitos: EQP-RF-02 (critérios 02.1 a 02.3)

## Como foi verificado
- [ ] Testes dos critérios
- [ ] Matriz atualizada

## Fora do escopo / riscos
## Mudanças na spec ou ADR?
```

Cada PR **responde as perguntas do revisor** antes que ele as faça.
