# Exercício 1: A revisão no PR

**Objetivo**: ligar a IA ao PR.

1. Crie uma etapa de revisão por IA que roda **depois** do pipeline verde.
2. Dê a ela: diff, Taskfile, requisitos e `docs/guidelines/revisao.md`.
3. Ela deve comentar no PR, por gravidade, **sem bloquear**.

**Observe**: os comentários eram úteis? Havia ruído?
