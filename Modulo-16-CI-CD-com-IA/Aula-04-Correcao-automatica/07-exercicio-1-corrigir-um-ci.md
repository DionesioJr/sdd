# Exercício 1: Corrija um CI

**Objetivo**: fazer o agente corrigir uma falha mecânica.

1. Provoque um erro de tipo num PR.
2. Entregue ao agente o **log do CI**, o Taskfile e o diff, com as regras do slide "Os limites".
3. Peça: *"Reproduza com `npm run test:docker` e corrija só o que o log aponta."*
4. Confira o commit.

**Observe**: ele respeitou o escopo? Mexeu em testes?
