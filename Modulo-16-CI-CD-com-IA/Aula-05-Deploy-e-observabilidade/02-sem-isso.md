# Deploy com medo e produção às cegas

- O deploy é manual, em horário estranho, com um roteiro que só uma pessoa conhece.
- Quando algo quebra, ninguém sabe **o que** foi para produção.
- Os usuários reportam o problema **antes** de vocês perceberem.

E, depois de resolvido, **nada volta para a spec**: o aprendizado se perde.
