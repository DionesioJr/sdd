# Observar a produção

| Sinal | Para que serve |
|---|---|
| **Logs** estruturados | O que aconteceu, quando e com quem |
| **Métricas** | Erros por minuto, tempo de resposta |
| **Health check** | O sistema está de pé? |
| **Alertas** | Avisar **antes** do usuário |

Cuidados:

- **Não registre dados pessoais** nem segredos nos logs (Módulo 18).
- Registre o **ID da requisição** para seguir um problema de ponta a ponta.
