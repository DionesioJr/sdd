# A produção volta à spec

Fluxo: Produção → Sinal (erro, uso, pedido) → Classificar → Bug, Feature ou Spec → Novo ciclo

- **Erro em produção** → **bug** (Módulo 14): reproduz, teste, corrige.
- **Uso inesperado** → pode ser **nova feature** ou **requisito mal entendido**.
- **Lentidão** → RNF de desempenho **ajustado** (e testado).

Cada incidente deve terminar numa **linha de spec** ou num **teste novo**.

Esse é o ciclo do SDD fechando: **o feedback é a próxima spec**.
