# O ganho real

| Sem isso | Com isso |
|---|---|
| Deploy manual, de risco | Deploy rotineiro e reversível |
| "O que está no ar?" | Tag e imagem versionadas |
| Usuário descobre o erro | Alerta antes do usuário |
| O aprendizado se perde | A produção alimenta a spec |

**Ganho real**: entregas frequentes e seguras, produção observável e um projeto que **aprende** com o que acontece nela.
