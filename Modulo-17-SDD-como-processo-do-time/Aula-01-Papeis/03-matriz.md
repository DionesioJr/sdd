# Quem faz o quê

| Documento | Escreve | Revisa | Aprova |
|---|---|---|---|
| Product Spec | Produto (com IA) | Tech lead, QA | **Produto** |
| Design e ADR | Dev sênior (com IA) | Tech lead | **Tech lead** |
| Tarefas | Dev (com IA) | Produto, QA | **Tech lead** |
| Código (PR) | Dev + agente | Outro dev + IA | **Dev revisor** |
| Testes | Dev + agente | QA | **QA** |
| Deploy | Pipeline | Dev | **Quem responde pelo ambiente** |

Em times pequenos, uma pessoa acumula papéis, mas o **papel** continua existindo.
