# O portão que ninguém sabe o que verifica

*"A spec foi aprovada."* Aprovada com base em quê?

- Uma pessoa leu por cima.
- Outra olhou só o título.
- A tarefa foi para implementação sem critérios de aceite, e ninguém notou.

Um portão sem **critério** é uma assinatura vazia.
