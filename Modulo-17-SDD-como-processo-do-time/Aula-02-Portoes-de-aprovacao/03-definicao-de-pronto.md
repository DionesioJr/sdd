# Definição de pronto, por fase

| Para entrar em… | Precisa de… |
|---|---|
| **Design** | Spec **aprovada**, critérios verificáveis, escopo e perguntas em aberto resolvidas |
| **Tarefas** | Design aprovado, ADRs das decisões difíceis, contratos definidos |
| **Implementação** | Tarefa com requisito, critérios, dependências e Taskfile (contexto certo) |
| **Merge** | Pipeline verde, PR ligado à spec, revisão aprovada |
| **Deploy** | Merge feito, ambiente verificado, rollback conhecido |

Cada linha é uma **lista de verificação** curta, e não um parágrafo.
