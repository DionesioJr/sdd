# Máquina ou pessoa?

Classifique cada item do portão:

| Item | Quem verifica |
|---|---|
| Tipos, testes, fronteiras, segurança | **Pipeline** |
| PR cita tarefa e requisito | **Pipeline** |
| Todos os critérios têm teste | **Pipeline** (matriz) |
| A spec resolve o problema certo | **Pessoa** |
| A decisão de design faz sentido | **Pessoa** |
| O risco é aceitável | **Pessoa** |

**Automatize o que for mecânico; reserve a atenção humana para o julgamento.**
