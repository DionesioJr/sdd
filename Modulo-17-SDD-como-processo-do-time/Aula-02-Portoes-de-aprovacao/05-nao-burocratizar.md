# Portões sem burocracia

Sinais de portão ruim:

- ninguém sabe o que é verificado;
- as pessoas **assinam sem ler**;
- espera de dias por aprovação;
- o portão é igual para tudo.

Correções:

- **proporcional ao risco** (Módulo 14: o bug não pede o mesmo que o produto novo);
- **prazo** para aprovar (ex.: um dia útil);
- **aprovação assíncrona** no PR.
