# Cada projeto, um jeito

- O projeto A tem `AGENTS.md` excelente; o B, nenhum.
- Cada pessoa escreve specs num formato.
- Uma skill valiosa existe só na máquina de uma pessoa.
- Uma pessoa nova leva semanas para entender "como se faz aqui".

O conhecimento **não circula** e a qualidade varia com quem está no projeto.
