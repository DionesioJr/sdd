# O kit do time

Um **repositório-modelo** (starter) com tudo pronto:

```
starter/
├── AGENTS.md
├── docs/
│   ├── _modelos/          ← domínio, módulo, ADR, estratégias
│   ├── guidelines/        ← testes, API, revisão
│   └── processo/          ← papéis, definição de pronto
├── skills/                ← criar-endpoint, revisar-contra-a-spec…
├── .github/               ← workflow de CI, template de PR
├── Dockerfile · compose.yaml
└── scripts/               ← matriz, verificação de PR
```

Projeto novo? **Copie o starter** e já nasce com o método.
