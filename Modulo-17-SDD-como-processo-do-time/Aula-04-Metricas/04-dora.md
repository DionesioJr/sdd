# DORA: entrega de software

Quatro métricas de referência para **desempenho de entrega**:

| Métrica | Pergunta |
|---|---|
| **Frequência de deploy** | Quantas vezes publicamos? |
| **Lead time de mudança** | Do commit à produção, quanto tempo? |
| **Taxa de falha de mudanças** | Quantos deploys causam problema? |
| **Tempo de restauração** | Quanto levamos para recuperar? |

IA pode **acelerar** as duas primeiras e **piorar** a terceira se o processo for frouxo.

**Velocidade e estabilidade andam juntas**: o objetivo é melhorar as duas.
