# O modelo certo para cada tarefa

| Tipo de tarefa | Modelo |
|---|---|
| Triagem, resumo, formatação, geração de modelo | **Pequeno e barato** |
| Implementar tarefa bem especificada | **Intermediário** |
| Planejar, projetar, revisão crítica, segurança | **Grande** |

Como o método **não depende do modelo** (Módulo 02), trocar é fácil.

Quanto **melhor a spec e o contexto**, **menor** o modelo que resolve. **Spec boa economiza dinheiro.**
