# Verificação automática

Acrescente ao pipeline (Módulo 16):

- **inventário de dependências** com as licenças (um SBOM, lista de componentes);
- **falha** se aparecer uma licença **proibida**;
- **alerta** para as que precisam de análise.

E uma regra no `AGENTS.md`: *"Não adicione dependências sem pedir."* (Módulo 15)

Guardar o inventário a cada versão dá **resposta pronta** para uma auditoria.
