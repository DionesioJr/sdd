# Dados pessoais

A **LGPD** (Lei Geral de Proteção de Dados) protege dados que identificam uma pessoa:

- **Pessoais**: nome, CPF, e-mail, telefone, endereço, IP.
- **Sensíveis**: saúde, biometria, origem racial, opinião política, religião, dados de crianças exigem atenção especial.

Pontos que afetam o uso de IA:

- **Minimização**: use o **mínimo** necessário.
- **Finalidade**: dados coletados para uma coisa não vão para outra.
- **Operador**: o provedor de IA que recebe os dados é um **terceiro**, e isso exige contrato e avaliação.
- **Transferência internacional**: enviar para fora do país tem regras.
