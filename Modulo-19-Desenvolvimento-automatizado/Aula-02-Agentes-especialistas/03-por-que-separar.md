# Por que separar as etapas

| Motivo | Efeito |
|---|---|
| **Contexto limpo** | Cada etapa começa só com o que precisa |
| **Visão independente** | O revisor não tem o viés do autor |
| **Permissões diferentes** | O revisor **lê**; não escreve |
| **Modelo certo** | Pequeno para triagem; grande para revisão |
| **Responsabilidade** | Cada etapa tem entrada, saída e critério |

É o mesmo princípio dos **papéis** do Módulo 17, agora entre agentes.
