# Passar o bastão

Entre as etapas, a informação trafega por **arquivos**, e não pela memória de uma sessão:

Fluxo: Implementa → `relatorio-implementacao.md` → Revisa → `relatorio-revisao.md` → Testa → `relatorio-teste.md`

- Cada relatório diz **o que foi feito**, **o que falta** e **o que o próximo precisa saber**.
- Se o revisor reprova, o **relatório vai ao implementador** (volta para a etapa anterior), com um **limite de voltas** (Aula 05).

Arquivos são **auditáveis** (Módulo 18): ficam no histórico.
