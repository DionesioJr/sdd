# Onde a pessoa aprova

No ciclo do SDD, os **portões** (Módulo 17) continuam:

Fluxo: Spec → **Aprovar** → Design → **Aprovar** → Plano → **Aprovar** → Execução (agentes) → **Aprovar o PR** (conforme o risco) → Deploy

- **Antes** da execução: quase tudo que **decide** (spec, design, plano) é humano.
- **Durante**: agentes, dentro dos limites.
- **Depois**: PR aprovado por pessoa, conforme o risco.

A autonomia **começa depois** das decisões, e não no lugar delas.
