# Os cinco limites

| Limite | Valor típico | Quando estoura |
|---|---|---|
| **Rodadas** | 2 a 3 voltas implementar/revisar | Para e escala |
| **Custo** | Teto por tarefa (Módulo 17) | Para e escala |
| **Tempo** | Máximo por etapa | Interrompe |
| **Escopo** | Só arquivos esperados | Reprova e para |
| **Risco** | Matriz de autonomia | Pede aprovação |

Quando **qualquer** limite estoura: **parar**, **registrar** e **chamar uma pessoa**, com um relatório do que foi tentado.
