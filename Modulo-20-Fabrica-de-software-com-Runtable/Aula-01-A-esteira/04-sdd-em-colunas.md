# O ciclo do SDD, em colunas

| Fase do SDD | Coluna | Agente |
|---|---|---|
| Especificar | Triagem e Refinamento | Requisitos e histórias |
| Projetar | Documentação (spec) | Documentação técnica |
| Implementar | Implementação | Desenvolvedor (backend, frontend) |
| Verificar | Revisão e Testes | Revisor de código, QA |
| Entregar | PR e merge, Entrega | DevOps |

Cada coluna é um **portão** (Módulo 17): a tarefa só avança se o critério de saída for cumprido.

Você já conhece cada etapa. **Agora elas têm um lugar**.
