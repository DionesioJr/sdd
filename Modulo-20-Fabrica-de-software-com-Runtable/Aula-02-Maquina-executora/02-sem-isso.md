# Onde o código é executado?

Duas dúvidas legítimas de um time:

- *"Meu código vai para a nuvem de outra empresa?"*
- *"O agente vai mexer na minha máquina como quiser?"*

Sem resposta clara, a adoção trava. Ou, pior, é feita sem perguntar, como um agente solto na máquina de alguém.
