# Resumo

- Os agentes rodam na **sua** máquina, em worktree isolada; a plataforma gerencia o fluxo.
- `rtb auth login` conecta; `rtb project add` vincula; `rtb serve` coloca online.
- Checagens bloqueantes são os portões do pipeline, aplicados antes do PR.
- Você escolhe o modelo; o vínculo é versionado.

**O ganho real**: agentes no seu ambiente, com controle.
