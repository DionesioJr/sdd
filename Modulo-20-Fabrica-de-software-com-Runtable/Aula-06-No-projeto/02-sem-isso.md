# Conhecer as peças não é saber operar a fábrica

Você já viu cada parte:

- spec, design e plano aprovados;
- contexto, testes, Docker e pipeline;
- agentes, limites, aprovações e governança.

Mas **operar** a fábrica com um domínio inteiro é outra experiência: decidir o que vai para a esteira, ler os relatórios, aprovar com critério, corrigir o método quando algo falha.
