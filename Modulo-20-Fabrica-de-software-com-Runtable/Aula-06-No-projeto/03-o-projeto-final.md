# O projeto final: o domínio Relatórios

**Objetivo**: entregar o domínio **Relatórios** do gestor pela esteira.

Fluxo: Spec → Revisão crítica → Plano por IA → Aprovação → Esteira → PRs → Revisão → Merge → Deploy

Você faz o papel de **tech lead**:

- **Escreve e aprova** a spec e o design;
- **Aprova o plano** da IA;
- **Define o risco** de cada tarefa;
- **Revisa** os PRs conforme a política;
- **Corrige o método** quando a esteira errar.

Os **agentes** fazem a execução.
