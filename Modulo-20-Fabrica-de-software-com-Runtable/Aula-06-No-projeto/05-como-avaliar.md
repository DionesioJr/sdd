# Como avaliar o resultado

| Pergunta | Onde olhar |
|---|---|
| Os critérios do domínio têm teste? | Matriz de rastreabilidade |
| Quantas tarefas foram aceitas de primeira? | Histórico das tarefas |
| Qual foi o custo por tarefa aceita? | Dossiê e painel de custo |
| Onde a esteira travou? | Retornos e escalonamentos |
| O que veio de spec ruim? | Causa dos retornos |
| Algo violou política ou segurança? | Trilha e revisão |

**Cada falha da fábrica** aponta para **um documento a melhorar**: spec, contexto, tarefa ou política. É o método (Módulo 08) em escala.
