# SDD e SPEC em uma frase

**SDD** (Spec-Driven Development): o método em que você define **o que é correto antes** de a IA codar, e **verifica depois** com testes.

**Spec**: o conjunto de documentos curtos que registram o correto: **o quê**, **como**, **em que ordem** e **com quais regras**.

Ciclo: Product Spec → Design → Tarefas → Implementação → Testes → Deploy

- A IA gera código **plausível**. A spec diz o que é **correto**.
- Cada documento responde **uma pergunta** só.
- Mudou o código? A spec muda **junto** (ou antes).
