# O mapa: os arquivos de um projeto

```
meu-projeto/
├── AGENTS.md                      regras fixas para o agente
├── docs/
│   ├── requirements.md            O QUÊ e para quem (Product Spec)
│   ├── design.md                  COMO será construído (Tech Spec)
│   ├── tasks.md                   O QUE FAZER e em que ordem
│   ├── architecture/adr/
│   │   └── 0001-sqlite-no-mvp.md  POR QUÊ decidimos assim
│   └── taskfiles/
│       └── T-03.md                COMO EXECUTAR uma tarefa
├── src/                           o código
└── tests/                         a prova dos critérios
```

Seis tipos de arquivo. **Um arquivo, uma pergunta.**

Quando o projeto crescer, cada arquivo vira uma **pasta** (Módulo 09).
