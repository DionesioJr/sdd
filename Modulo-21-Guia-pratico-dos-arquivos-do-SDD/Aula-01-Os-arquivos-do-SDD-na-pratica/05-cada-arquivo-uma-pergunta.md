# Cada arquivo: pergunta, nascimento e mudança

| Arquivo | Pergunta | Nasce | Muda quando |
|---|---|---|---|
| `requirements.md` | O quê e para quem? | Da ideia, antes de tudo | O comportamento esperado muda |
| `design.md` | Como será construído? | Com o requirements aprovado | Stack, dados ou API mudam |
| ADR | Por que decidimos assim? | Na decisão difícil de reverter | Nunca é editado: é **substituído** |
| `tasks.md` | O que fazer, em que ordem? | Com o design aprovado | Toda feature nova; marca `[x]` ao concluir |
| Taskfile | Como executar esta tarefa? | Logo antes de executar | Não muda: é arquivado ao concluir |
| `AGENTS.md` | O que o agente sempre precisa saber? | No dia 1, curto | Erro recorrente vira uma linha |
