# Seis erros que desfazem o método

| Erro | O que acontece | O certo |
|---|---|---|
| Corrigir o bug direto no código | O bug volta e a spec mente | Teste que falha e, se faltava, o critério |
| Não marcar `[x]` no `tasks.md` | O plano não mostra o que falta | Marcar no mesmo commit da tarefa |
| `AGENTS.md` de 300 linhas | O agente ignora e o custo sobe | Uma linha por erro recorrente |
| Editar um ADR antigo | Perde-se o porquê | Novo ADR que substitui |
| Pular a aprovação | O erro da spec vira erro do código | Ler e aprovar cada documento |
| Especificar o sistema todo antes do MVP | Cascata, e nada é validado | Spec completa só do MVP |
