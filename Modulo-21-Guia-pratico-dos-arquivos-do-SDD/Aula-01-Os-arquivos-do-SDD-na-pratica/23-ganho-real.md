# O ganho real

| Sem isso | Com isso |
|---|---|
| Arquivos criados e esquecidos | Cada arquivo com momento e uso definidos |
| Bug corrigido no chat | Teste que falha e passa, critério na spec |
| Feature direto no código | Mini-spec, design só do afetado, tarefas |
| Agente recebe tudo, ou nada | `AGENTS.md` sempre, Taskfile por tarefa |
| "Por que isso existe?" sem resposta | Histórico do Git: pedido, spec, teste, código |

**Ganho real**: a spec continua sendo **verdade** depois do MVP, e cada pedido novo já tem um caminho.
